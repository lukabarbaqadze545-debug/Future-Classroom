# თავი 3. ციკლები
weeks: 3

ციკლი ბრძანებათა ჯგუფს მრავალჯერ ასრულებს: `for`, `while`, ჩადგმული ციკლები, ციკლიდან გასვლა `break`-ით. ახალი საფრთხეც ჩნდება: ციკლს შეუძლია ძალიან ბევრჯერ შესრულდეს და რიცხვებმა ციკლში `int` გადააჭარბოს.

წინაპირობა: პირობითი ოპერატორები. ამ თავში ხშირად დაგჭირდებათ ცვლადი, რომელიც ციკლის დროს გროვდება (ჯამი, ნამრავლი, მრიცხველი): დაიწყეთ მისი სწორი საწყისი მნიშვნელობით.

## რიცხვები 1-დან n-მდე
level: 1
tags: for, ციკლი

შეყვანილია `n`. გამოიტანეთ რიცხვები 1-დან `n`-მდე ერთ ხაზზე, ინტერვალებით გამოყოფილი.

### შეყვანა

ერთი მთელი რიცხვი `n`.

### გამოტანა

ერთი ხაზი: `1 2 ... n`.

### შეზღუდვები

1 ≤ n ≤ 1000

### მაგალითი

```in
5
```

```out
1 2 3 4 5
```

### შემოწმება

```in
1
```

```out
1
```

### მინიშნებები

1. ერთი და იგივე მოქმედება `n`-ჯერ მეორდება, ოღონდ ყოველ ჯერზე სხვა რიცხვით.
2. `for (int i = 1; i <= n; i++)`.
3. გამოიტანეთ `i` ციკლში. ინტერვალი გამოიტანეთ მხოლოდ პირველის შემდეგ ან `i`-ს შემდეგ; გამოტანის ბოლოს დამატებული ინტერვალი შეფასებაზე არ მოქმედებს.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cout << i << " ";
    }
    cout << endl;
    return 0;
}
```

`for`-ის სამი ნაწილია: საწყისი მნიშვნელობა (`int i = 1`), გაგრძელების პირობა (`i <= n`) და ნაბიჯი (`i++`). პირობაში `<=` და `<` არ აურიოთ: ამ ამოცანაში `n` თვითონაც უნდა დაიბეჭდოს.

## ჯამი 1-დან n-მდე
level: 1
tags: for, ჯამი, long long

გამოთვალეთ რიცხვების ჯამი 1-დან `n`-მდე: `1 + 2 + … + n`.

### გამოტანა

### შეზღუდვები

1 ≤ n ≤ 10⁶

### მაგალითი

```in
10
```

```out
55
```

### მაგალითი

```in
1000000
```

```out
500000500000
```

### მინიშნებები

1. დაგვჭირდება ცვლადი, რომელშიც ჯამი გროვდება. რა მნიშვნელობით დაიწყებთ?
2. ჯამს ნულიდან იწყებთ და ციკლში ყოველ ჯერზე ემატება მიმდინარე რიცხვი.
3. შეამოწმეთ ზღვრული ტესტზე: `n = 10⁶`-ისთვის ჯამი დაახლოებით 5 · 10¹¹-ია. რომელი ტიპი იტევს ამას?

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }
    cout << sum << endl;
    return 0;
}
```

ჯამისთვის `long long` გვჭირდება: `int` ამ ჯამს ვერ დაიტევს. გროვდებადი ცვლადის (`sum`) საწყისი მნიშვნელობა აუცილებლად უნდა მიეცეს: მის გარეშე ცვლადში შემთხვევითი ნაგავია. თუ ფორმულა გახსოვთ, `n * (n + 1) / 2` იგივე პასუხს იძლევა ციკლის გარეშე.

## რამდენი რიცხვი იყოფა k-ზე
level: 2
tags: for, %, დათვლა

დაითვალეთ, რამდენი რიცხვი იყოფა `k`-ზე მთელი რიცხვების მიმდევრობაში `a`-დან `b`-მდე (ორივე ბოლო ჩათვლით).

### შეყვანა

ერთ ხაზზე სამი მთელი რიცხვი `a`, `b`, `k`.

### გამოტანა

ერთი რიცხვი: რაოდენობა.

### შეზღუდვები

1 ≤ a ≤ b ≤ 10⁶, 1 ≤ k ≤ 10⁶

### მაგალითი

```in
1 10 3
```

```out
3
```

### განმარტება

3-ზე იყოფა 3, 6 და 9.

### მაგალითი

```in
7 9 5
```

```out
0
```

### შემოწმება

```in
5 5 5
```

```out
1
```

### მინიშნებები

1. გაიარეთ ყველა რიცხვი ინტერვალში და ყოველივე შეამოწმეთ.
2. რიცხვი `x` იყოფა `k`-ზე, თუ `x % k == 0`.
3. დაიწყეთ მრიცხველი ნულიდან; ციკლში `a`-დან `b`-მდე გაზარდეთ ის ყოველი გაყოფადი `x`-ისთვის.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, k;
    cin >> a >> b >> k;
    int count = 0;
    for (int x = a; x <= b; x++) {
        if (x % k == 0) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

ეს არის „დათვლის“ ტიპური სქემა: მრიცხველი, ციკლი, პირობა. ინტერვალი 10⁶-მდეა, ამიტომ მილიონი შემოწმება ერთ წამზე გაცილებით სწრაფია. იგივე ამოცანა ციკლის გარეშეც იხსნება ფორმულით `b / k - (a - 1) / k`; შეადარეთ ისინი ერთმანეთს.

### სტრესი

```brute
#include <iostream>
using namespace std;

int main() {
    int a, b, k;
    cin >> a >> b >> k;
    cout << b / k - (a - 1) / k << endl;
    return 0;
}
```

```gen
print(a, b, random.randint(1, 12))
```

## ფაქტორიალი
level: 2
tags: for, ნამრავლი, long long

რიცხვის ფაქტორიალია ნამრავლი `1 · 2 · … · n`; ნულის ფაქტორიალი 1-ია. გამოთვალეთ `n!`.

### შეყვანა

### გამოტანა

ერთი რიცხვი: `n!`.

### შეზღუდვები

0 ≤ n ≤ 20

### მაგალითი

```in
5
```

```out
120
```

### მაგალითი

```in
0
```

```out
1
```

### მაგალითი

```in
20
```

```out
2432902008176640000
```

### მინიშნებები

1. ჯამში ნულიდან იწყებდით. რა მნიშვნელობით დაიწყებთ ნამრავლს?
2. ნამრავლის საწყისი მნიშვნელობა 1-ია: ნული ყველაფერს გააბათილებდა.
3. `n = 0`-ზე ციკლი არ შესრულდება და პასუხი იქნება საწყისი მნიშვნელობა. 20! დაახლოებით 2,4 · 10¹⁸-ია: შეარჩიეთ ტიპი.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    cout << result << endl;
    return 0;
}
```

ფაქტორიალი სწრაფად იზრდება: 13! უკვე აღემატება `int`-ის ზღვარს, ხოლო 21! არ ეტევა `long long`-შიც. ამიტომ ამოცანაში `n ≤ 20`. ციკლი 2-დან იწყება, რადგან 1-ზე გამრავლება არაფერს ცვლის.

## ხარისხი
level: 2
tags: for, ნამრავლი, long long

გამოთვალეთ `a` ხარისხში `n`, ციკლით, ბიბლიოთეკური ფუნქციის გარეშე.

### შეყვანა

### გამოტანა

### შეზღუდვები

1 ≤ a ≤ 10⁹, 0 ≤ n ≤ 60. გარანტირებულია, რომ `aⁿ ≤ 10¹⁸`.




```out

```

### შემოწმება

```in

```

```out

```

```in

```

```out

```

### მინიშნებები

1. `a` ხარისხში `n` არის `a`-ს გამრავლება თავის თავზე `n`-ჯერ. რა მიიღება `n = 0`-ზე?
2. დაიწყეთ 1-ით და `n`-ჯერ გაამრავლეთ `a`-ზე.
3. ცვლადი `result` იყოს `long long`. `pow` ფუნქცია არ გამოიყენოთ: ის ათწილადი რიცხვებით მუშაობს და დიდ პასუხზე სიზუსტეს კარგავს.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long a;
    int n;
    cin >> a >> n;
    long long result = 1;
    for (int i = 0; i < n; i++) {
        result *= a;
    }
    cout << result << endl;
    return 0;
}
```

ციკლი ზუსტად `n`-ჯერ სრულდება (`i` 0-დან `n - 1`-მდე). `n = 0` ციკლს საერთოდ არ გაუშვებს და პასუხი ისევ 1-ია, რაც მათემატიკურად სწორია. `pow` ათწილადებს აბრუნებს: `pow(10, 18)` შეიძლება `999999999999999999`-ად დაიწეროს.

## ჯამი, მინიმუმი და მაქსიმუმი

tags: for, მინიმუმი, მაქსიმუმი, ჯამი

### შეყვანა

### გამოტანა

### მაგალითი

### მინიშნებები

1. ჯამი თანდათან გროვდება. მინიმუმისა და მაქსიმუმისთვის კი ყოველ ახალ რიცხვს „ჩამრჩენ“ რიცხვთან ვადარებთ.
2. პირველი რიცხვი გამოიყენეთ მინიმუმისა და მაქსიმუმის საწყის მნიშვნელობად. რატომ არ გამოდგება საწყისად 0?
3. წაიკითხეთ პირველი რიცხვი, ჩაწერეთ `sum`, `lo`, `hi`-ში; დანარჩენ `n - 1` რიცხვზე განაახლეთ სამივე.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long sum = 0;
    int lo = 0, hi = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        sum += x;
        if (i == 0 || x < lo) lo = x;
        if (i == 0 || x > hi) hi = x;
    }
    cout << sum << " " << lo << " " << hi << endl;
    return 0;
}
```

ნული საწყის მინიმუმად არ გამოდგება: თუ ყველა რიცხვი დადებითია, პასუხი მცდარად 0 გამოვა. ამიტომ პირველივე რიცხვი ინიციალიზაციას აკეთებს (`i == 0`). ჯამი `long long`-ია, რადგან 10⁵ რიცხვის ჯამი 10¹⁴-მდეა.

### სტრესი

```brute
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> v(n);
    long long sum = 0;
    for (auto &x : v) {
        cin >> x;
        sum += x;
    }
    cout << sum << " " << *min_element(v.begin(), v.end()) << " " << *max_element(v.begin(), v.end()) << endl;
    return 0;
}
```

## შეყვანა ნულამდე
level: 2
tags: while, cin, შეყვანის წაკითხვა

პროგრამას რიცხვები შემოდის სათითაოდ, ინტერვალით ან ხაზის გადატანით გამოყოფილი. შეყვანა მთავრდება რიცხვით 0 (ის დამუშავებას აღარ ექვემდებარება). გამოიტანეთ, რამდენი რიცხვი შეიყვანეს ნულამდე და რა არის მათი ჯამი.

### გამოტანა

### მინიშნებები

1. წინასწარ არ იცით, რამდენი რიცხვი იქნება, ამიტომ `for` რიცხვზე დაფუძნებით არ გამოდგება.
2. გამოიყენეთ `while`, რომელიც ერთ რიცხვს კითხულობს და ჯერ ამოწმებს, ნული ხომ არაა.
3. `while (cin >> x && x != 0)` ერთდროულად კითხულობს და ამოწმებს. ჯამი აკეთეთ `long long`-ში.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long x, sum = 0;
    int count = 0;
    while (cin >> x && x != 0) {
        count++;
        sum += x;
    }
    cout << count << " " << sum << endl;
    return 0;
}
```

`cin >> x` თვითონ არის პირობა: ის „ჭეშმარიტია“, თუ რიცხვი წარმატებით წაიკითხა. `&&` მეორე ნაწილს მხოლოდ მაშინ ამოწმებს, როცა პირველი ჭეშმარიტია. ამ სქემით პროგრამა შეყვანის დასრულებაზეც არ იჭედება, თუნდაც 0 არ იყოს ბოლოს.

## ვარსკვლავების სამკუთხედი
level: 2
tags: ჩადგმული ციკლები, გამოტანის ფორმატი

გამოიტანეთ `n` ხაზი: `i`-ურ ხაზში `i` ვარსკვლავია (`*`).

### შეყვანა

ერთი მთელი რიცხვი `n`.

### გამოტანა

`n` ხაზი ვარსკვლავებით, ინტერვალების გარეშე.

### შეზღუდვები

1 ≤ n ≤ 50

### მაგალითი

```in
3
```

```out
*
**
***
```

### შემოწმება

```in
1
```

```out
*
```

### მინიშნებები

1. თითოეული ხაზი ცალკე მოქმედებაა: მისი ბოლოს ხაზი უნდა გადავიდეს.
2. გარე ციკლი გადის ხაზებს, შიდა ციკლი ხაზში ვარსკვლავებს.
3. `i`-ური ხაზის შიდა ციკლი `i`-ჯერ იმეორებს `cout << '*'`; შემდეგ `cout << endl`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            cout << '*';
        }
        cout << endl;
    }
    return 0;
}
```

გარე ციკლი ხაზებს ითვლის, შიდა — ერთ ხაზზე სიმბოლოებს. სწორი რიგი: `endl` ეკუთვნის გარე ციკლს და შიდა ციკლის შემდეგ სრულდება. თუ ის შიდა ციკლში მოხვდება, ყოველი ვარსკვლავი ახალ ხაზზე გამოვა.

## გამრავლების ცხრილი

გამოიტანეთ გამრავლების ცხრილი `n × n` ზომის: `i`-ურ ხაზში მოცემულია `i · 1`, `i · 2`, …, `i · n`, ინტერვალებით გამოყოფილი.

### გამოტანა

`n` ხაზი, თითოეულში `n` რიცხვი.

### მინიშნებები

1. ცხრილში სტრიქონიც და სვეტიც ციკლია.
2. გარეთა ციკლი `i`-ს ცვლის, შიდა `j`-ს. რას უდრის უჯრა `(i, j)`?
3. გამოიტანეთ `i * j` შიდა ციკლში ინტერვალით. `endl` შიდა ციკლის შემდეგ.

```cpp
#include <iostream>

int main() {
```

## ფიბონაჩის რიცხვი
level: 2
tags: for, მიმდევრობა, long long

ფიბონაჩის მიმდევრობაში პირველი ორი წევრი 1-ია, ყოველი შემდეგი კი წინა ორის ჯამია: 1, 1, 2, 3, 5, 8, … გამოიტანეთ `n`-ური წევრი.

### შეყვანა

ერთი მთელი რიცხვი `n`.

### გამოტანა

ერთი რიცხვი: `n`-ური ფიბონაჩის რიცხვი.

### შეზღუდვები

1 ≤ n ≤ 90

### მაგალითი

```in
10
```

```out
55
```

### მაგალითი

```in
2
```

```out
1
```

### შემოწმება

```in
1
```

```out
1
```

```in
90
```

```out
2880067194370816120
```

### მინიშნებები

1. ყოველი ახალი წევრისთვის საკმარისია წინა ორის ცოდნა.
2. შეინახეთ მხოლოდ ორი ცვლადი (წინა და ამჟამინდელი) და ციკლში გადაადგილეთ.
3. დაიწყეთ `a = 1`, `b = 1`; `n - 1` ან `n - 2` ნაბიჯი, ყოველ ჯერზე `c = a + b; a = b; b = c;`. 90-ე წევრი 10¹⁸-ზე მეტია: ტიპი აირჩიეთ.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long a = 1, b = 1;
    for (int i = 3; i <= n; i++) {
        long long c = a + b;
        a = b;
        b = c;
    }
    cout << b << endl;
    return 0;
}
```

წყვილი `(a, b)` ყოველ ნაბიჯზე ერთი პოზიციით გადაადგილდება: `a` წინა წევრია, `b` — მიმდინარე. თუ `n` არის 1 ან 2, ციკლი არ სრულდება და `b` ისევ 1-ია. 93-ე წევრიდან ფიბონაჩი უკვე `long long`-ს აღემატება.

## კოლაცის ბიჯები
level: 3
tags: while, long long, სიმულაცია

აიღეთ დადებითი რიცხვი `n`. თუ ის ლუწია, გაყავით 2-ზე; თუ კენტია, გაამრავლეთ 3-ზე და დაუმატეთ 1. გაიმეორეთ, სანამ რიცხვი არ გახდება 1. გამოიტანეთ ბიჯების რაოდენობა.

### შეყვანა

### გამოტანა

### შეზღუდვები

1 ≤ n ≤ 10⁶. (გარანტირებულია, რომ პროცესი მთავრდება.)

```out
8
```

### განმარტება

### მაგალითი

```in
1
```

```out
0
```



### მინიშნებები

1. ბიჯების რაოდენობა წინასწარ უცნობია. რომელი ციკლი გამოდგება?
2. `while (n != 1)`: ამ ციკლის ტანში გააკეთეთ ერთი გადასვლა და გაზარდეთ მრიცხვი.
3. შუალედური მნიშვნელობები საწყისზე ბევრად დიდია: მაგალითად, `n = 837799`-ის გზაზე რიცხვი დაახლოებით 3 · 10⁹-მდე იზრდება, ეს `int`-ის ზღვარს აღემატება. შეარჩიეთ ტიპი სწორად.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    int steps = 0;
    while (n != 1) {
        if (n % 2 == 0) {
            n /= 2;
        } else {
            n = 3 * n + 1;
        }
        steps++;
    }
    cout << steps << endl;
    return 0;
}
```

საწყისი რიცხვი მცირეა, მაგრამ `3n + 1` გზაზე მას ძალიან ზრდის. `int` ზოგიერთ შემთხვევაში გადაივსებოდა და ციკლი უსასრულოდ ან მცდარ შედეგამდე მიიყვანდა. ეს ცნობილი ჰიპოთეზაა (კოლაცის ამოცანა): არავის დაუმტკიცებია, რომ ყველა რიცხვისთვის პროცესი მთავრდება.

## გაორმაგება
level: 2
tags: while, long long, სიმულაცია

ბაქტერიების კოლონიაში თავდაპირველად 1 ბაქტერიაა და ყოველ საათში მათი რაოდენობა ორმაგდება. რამდენი სრული საათი გავა, სანამ ბაქტერიების რაოდენობა `n`-ზე მეტი გახდება?

### შეყვანა

ერთი მთელი რიცხვი `n`.

### გამოტანა

ერთი რიცხვი: საათების რაოდენობა.

### შეზღუდვები

1 ≤ n ≤ 10¹⁸

### მაგალითი

```in
1
```

```out
1
```

### განმარტება

დასაწყისში ბაქტერია 1-ია; 1 საათის შემდეგ 2 გახდება, ანუ `n = 1`-ზე მეტი.

### მაგალითი

```in
10
```

```out

```

```in

```


### მინიშნებები

1. სიმულაცია: დაიცადეთ საათი და გაორმაგეთ, სანამ პირობა არ შესრულდება.
2. ციკლის პირობა გამოხატავს „ჯერ არ გადაჭარბებულა“: `count <= n`.
3. დაიწყეთ `count = 1`, `hours = 0`. ციკლში `count *= 2; hours++;`. `count` უნდა იყოს `long long`: 2⁶⁰ ≈ 1,15 · 10¹⁸.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    long long count = 1;
    int hours = 0;
    while (count <= n) {
        count *= 2;
        hours++;
    }
    cout << hours << endl;
    return 0;
}
```

`while` ციკლი ჯერ პირობას ამოწმებს. `n = 1`-ზე `count <= n` ჭეშმარიტია, ამიტომ ერთი გაორმაგება მაინც შესრულდება. პროგრამა საუკეთესოდ აჩვენებს, რომ ორობითი ზრდა სწრაფია: მილიარდობით ბაქტერიას 30 საათი ეყოფა.
