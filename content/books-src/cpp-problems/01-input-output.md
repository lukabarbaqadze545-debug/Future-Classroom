# თავი 1. შეყვანა, გამოტანა და არითმეტიკა
weeks: 1–2

ამ თავში ვივარჯიშებთ პროგრამის ყველაზე მარტივ სტრუქტურაზე: წავიკითხოთ რიცხვები (`cin`), გამოვთვალოთ და გამოვიტანოთ პასუხი (`cout`). ახალ ცნებებად გვხვდება ცვლადის ტიპი (`int`, `long long`, `double`), მთელი გაყოფა და ნაშთი (`/`, `%`), გამოტანის ფორმატი და ტიპის გადავსება.

წინაპირობა: ერთხელ მაინც დაწერილი და გაშვებული პროგრამა. თუ კომპილაციის შეტყობინებები ჯერ არ გესმით, მათ წაკითხვას დაუთმეთ დრო: ისინი სწორედ გეუბნებიან, სად არის შეცდომა.

## პირველი პროგრამა
level: 1
tags: cout, პირველი პროგრამა

დაწერეთ პროგრამა, რომელიც ეკრანზე გამოიტანს ტექსტს `Hello, C++!`.

### შეყვანა

პროგრამას შეყვანა არ აქვს.

### გამოტანა

ერთი ხაზი: `Hello, C++!`

### მაგალითი

```out
Hello, C++!
```

### მინიშნებები

1. იფიქრეთ იმაზე, რომელი სათაურია საჭირო `cout`-ის გამოსაყენებლად და რა როლი აქვს `main`-ს.
2. გამოსატანი ტექსტი ბრჭყალებშია და `cout`-ს გადაეცემა ოპერატორით `<<`.
3. ჩართეთ `<iostream>`, დაწერეთ `main`, გამოიტანეთ ტექსტი და ხაზის გადატანა, ბოლოს დააბრუნეთ 0.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++!" << endl;
    return 0;
}
```

`#include <iostream>` ამატებს შეყვანა-გამოტანის შესაძლებლობებს, `cout << ...` კი ეკრანზე წერს. `endl` გადადის ახალ ხაზზე.

ხშირი შეცდომები: დავიწყებული წერტილ-მძიმე (`;`) ხაზის ბოლოს, ერთი ბრჭყალი ორის მაგივრად, `Cout` დიდი ასოთი (C++ განასხვავებს დიდ და პატარა ასოებს).

## ორი რიცხვის ჯამი
level: 1
tags: cin, int, არითმეტიკა

შეყვანილია ორი მთელი რიცხვი. გამოიტანეთ მათი ჯამი.

### შეყვანა

ერთ ხაზზე ორი მთელი რიცხვი `a` და `b`, გამოყოფილი ინტერვალით.

### გამოტანა

ერთი რიცხვი: `a + b`.

### შეზღუდვები

−10⁹ ≤ a, b ≤ 10⁹

### მაგალითი

```in
3 5
```

```out
8
```

### მაგალითი

```in
-4 10
```

```out
6
```

### მინიშნებები

1. რიცხვები ჯერ ცვლადებში უნდა შეინახოთ. რომელი ტიპის?
2. `cin >> a >> b;` კითხულობს ორ რიცხვს ერთმანეთის მიყოლებით.
3. გამოაცხადეთ ორი `int` ცვლადი, წაიკითხეთ, გამოიტანეთ `a + b`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```

ორი რიცხვის ჯამი, რომელთაგან თითოეული არ აღემატება 10⁹-ს, ეტევა `int`-ში (მისი ზღვარი დაახლოებით 2,1 · 10⁹). შემდეგი თავის ამოცანებში ეს უკვე ასე აღარ იქნება.

## სამი მოქმედება
level: 1
tags: cin, არითმეტიკა, ტიპები

მოცემულია ორი მთელი რიცხვი `a` და `b`. გამოიტანეთ სამი ხაზი: მათი ჯამი, სხვაობა (`a − b`) და ნამრავლი.

### შეყვანა

ერთ ხაზზე ორი მთელი რიცხვი `a` და `b`.

### გამოტანა

სამი ხაზი: `a + b`, `a - b`, `a * b`.

### შეზღუდვები

−10⁴ ≤ a, b ≤ 10⁴

### მაგალითი

```in
7 3
```

```out
10
4
21
```

### მინიშნებები

1. გაითვალისწინეთ, რომ გამოსატანია სამი ცალკე ხაზი.
2. ხაზის გადასატანად გამოიყენეთ `endl` ან `"\n"`.
3. ერთი `cout` ბრძანებით შეიძლება რამდენიმე რამის გამოტანა: `cout << x << endl << y << endl;`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    cout << a - b << endl;
    cout << a * b << endl;
    return 0;
}
```

ყურადღება მიაქციეთ რიგს: სხვაობა `a - b` და არა `b - a`. ნამრავლი 10⁸-ს არ აღემატება, ამიტომ `int` საკმარისია.

## გაყოფა და ნაშთი
level: 1
tags: /, %, მთელი გაყოფა

შეყვანილია ორი მთელი რიცხვი. გამოიტანეთ პირველის მეორეზე მთელი გაყოფის შედეგი (განაყოფი) და ნაშთი.

### შეყვანა

ერთ ხაზზე ორი რიცხვი `a` და `b`.

### გამოტანა

ორი რიცხვი ერთ ხაზზე ინტერვალით გამოყოფილი: `a / b` და `a % b`.

### შეზღუდვები

0 ≤ a ≤ 10⁹, 1 ≤ b ≤ 10⁹

### მაგალითი

```in
17 5
```

```out
3 2
```

### განმარტება

17 = 3 · 5 + 2, ამიტომ განაყოფია 3, ნაშთი კი 2.

### მაგალითი

```in
4 9
```

```out
0 4
```

### შემოწმება

```in
0 7
```

```out
0 0
```

```in
1000000000 1
```

```out
1000000000 0
```

### მინიშნებები

1. C++-ში ორი მთელი რიცხვის გაყოფა მთელ რიცხვს იძლევა. რომელი ოპერატორი იძლევა ნაშთს?
2. განაყოფისთვის `/`, ნაშთისთვის `%`.
3. წაიკითხეთ `a` და `b`, გამოიტანეთ `a / b`, ინტერვალი და `a % b` ერთ ხაზზე.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a / b << " " << a % b << endl;
    return 0;
}
```

მთელ რიცხვებზე `/` აგდებს წილად ნაწილს (17 / 5 არის 3 და არა 3,4), `%` კი გვიბრუნებს ნაშთს. ეს ორი ოპერატორი წიგნში ხშირად გამოგადგებათ: ციფრებთან, საათებთან, ციკლურ მიმდევრობებთან.

## დიდი ჯამი
level: 1
tags: long long, გადავსება

შეყვანილია ორი მთელი რიცხვი. გამოიტანეთ მათი ჯამი. რიცხვები იმდენად დიდია, რომ `int` ვერ დაიტევს.

### შეყვანა

ერთ ხაზზე ორი მთელი რიცხვი `a` და `b`.

### გამოტანა

ერთი რიცხვი: `a + b`.

### შეზღუდვები

−2 · 10¹⁸ ≤ a, b ≤ 2 · 10¹⁸

### მაგალითი

```in
2000000000 2000000000
```

```out
4000000000
```

### მაგალითი

```in
1000000000000000000 -2000000000000000000
```

```out
-1000000000000000000
```

### შემოწმება

```in
2000000000000000000 2000000000000000000
```

```out
4000000000000000000
```

### მინიშნებები

1. რა მაქსიმალურ რიცხვს იტევს `int`? შეადარეთ ის პირობის შეზღუდვებს.
2. არსებობს უფრო დიდი მთელი ტიპი, `long long`; ის დაახლოებით 9 · 10¹⁸-მდე იტევს.
3. გამოაცხადეთ `a` და `b` ტიპით `long long`, წაიკითხეთ და გამოიტანეთ ჯამი. შეამოწმეთ პირველ მაგალითზე, რომ პასუხი 4000000000-ია.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```

`int` ჩვეულებრივ 32 ბიტიანია და 2147483647-მდე იტევს. მისგან უფრო დიდი რიცხვის ჩაწერისას პროგრამა **გადავსებას** იძლევა: პასუხი უაზროა, შეცდომა კი არ ჩანს. `long long` 64 ბიტიანია და საკმარისია. წესი, რომელიც ბევრ ამოცანაში გამოგადგებათ: ჯერ შეზღუდვები შეამოწმეთ, მერე აირჩიეთ ტიპი.

## საშუალო არითმეტიკული
level: 2
tags: double, setprecision, გამოტანის ფორმატი

შეყვანილია სამი მთელი რიცხვი. გამოიტანეთ მათი საშუალო არითმეტიკული ზუსტად ორი ციფრით წერტილის შემდეგ.

### შეყვანა

ერთ ხაზზე სამი მთელი რიცხვი.

### გამოტანა

ერთი ათწილადი რიცხვი ორი ციფრით წერტილის შემდეგ.

### შეზღუდვები

−1000 ≤ რიცხვი ≤ 1000

### მაგალითი

```in
1 2 4
```

```out
2.33
```

### განმარტება

(1 + 2 + 4) / 3 = 7 / 3 = 2,3333…, ორ ციფრამდე დამრგვალებული არის 2,33.

### მაგალითი

```in
-3 0 5
```

```out
0.67
```

### შემოწმება

```in
1 1 1
```

```out
1.00
```

```in
-1 0 0
```

```out
-0.33
```

### მინიშნებები

1. რა მიიღება, თუ `int`-ს `int`-ზე გაყოფთ? სცადეთ `7 / 3`.
2. საკმარისია, რომ ერთი რიცხვი იყოს ათწილადი (`3.0`), მაშინ მთელი გაყოფა აღარ მოხდება.
3. გამოთვალეთ `(a + b + c) / 3.0` ცვლადში `double`. გამოსატანად ჩართეთ `<iomanip>` და გამოიყენეთ `fixed << setprecision(2)`.

### ამოხსნა

```cpp
#include <iomanip>
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    double average = (a + b + c) / 3.0;
    cout << fixed << setprecision(2) << average << endl;
    return 0;
}
```

`3.0` არის `double`, ამიტომ მთელი ჯამიც `double`-ად გარდაიქმნება და გაყოფა ზუსტია. `fixed << setprecision(2)` მიუთითებს ზუსტად 2 ციფრს წერტილის შემდეგ. `setprecision(2)` მარტო მიუთითებდა ორ **მნიშვნელოვან** ციფრს და გამოტანა იქნებოდა `2.3`.

ხშირი შეცდომა: `(a + b + c) / 3` მთელი გაყოფაა. 7 / 3 ამ შემთხვევაში არის 2 და გამოტანა გამოვა `2.00`.

## წუთები საათებად
level: 1
tags: /, %, დრო

ინტერვალი მოცემულია წუთებით. გამოთვალეთ, რამდენი სრული საათი და კიდევ რამდენი წუთია მასში.

### შეყვანა

ერთი მთელი რიცხვი `n`: წუთების რაოდენობა.

### გამოტანა

ორი რიცხვი ერთ ხაზზე: სრული საათების რაოდენობა და დარჩენილი წუთები.

### შეზღუდვები

0 ≤ n ≤ 10⁶

### მაგალითი

```in
135
```

```out
2 15
```

### მაგალითი

```in
45
```

```out
0 45
```

### მინიშნებები

1. ერთ საათში 60 წუთია. რამდენჯერ ეტევა 60 რიცხვში `n`?
2. სრული საათები არის მთელი გაყოფა, დარჩენილი წუთები არის ნაშთი.
3. გამოთვალეთ `n / 60` და `n % 60`, გამოიტანეთ ერთ ხაზზე.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    cout << n / 60 << " " << n % 60 << endl;
    return 0;
}
```

ეს იგივე სქემაა, როგორც „გაყოფა და ნაშთი“ ამოცანაში: მთელი გაყოფა ითვლის „სრულ ჯგუფებს“, ნაშთი კი დარჩენილს. მსგავსად გამოითვლება კვირის დღეები, საათის ციფერბლატი და სხვა ციკლური მნიშვნელობები.

## საათის ფორმატი
level: 2
tags: setw, setfill, დრო, გამოტანის ფორმატი

შუაღამიდან გასული დრო მოცემულია წამებში. გამოიტანეთ ის ფორმატით `სს:წწ:წმწმ` (საათი, წუთი, წამი), სადაც ყოველი ნაწილი ორნიშნაა და საჭიროების შემთხვევაში ნულით იწყება.

### შეყვანა

ერთი მთელი რიცხვი `n`: წამების რაოდენობა.

### გამოტანა

დრო ფორმატით `HH:MM:SS`.

### შეზღუდვები

0 ≤ n < 86400

### მაგალითი

```in
3661
```

```out
01:01:01
```

### მაგალითი

```in
45296
```

```out
12:34:56
```

### შემოწმება

```in
0
```

```out
00:00:00
```

```in
86399
```

```out
23:59:59
```

### მინიშნებები

1. ჯერ გაყავით დრო საათებად, წუთებად და წამებად. საათში 3600 წამია, წუთში 60.
2. საათები: `n / 3600`. წუთები: დარჩენილი ნაწილის 60-ზე გაყოფა. წამები: `n % 60`.
3. ორნიშნა გამოტანისთვის გამოიყენეთ `<iomanip>`-ის `setw(2)` და `setfill('0')`.

### ამოხსნა

```cpp
#include <iomanip>
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int hours = n / 3600;
    int minutes = n % 3600 / 60;
    int seconds = n % 60;
    cout << setfill('0') << setw(2) << hours << ':' << setw(2) << minutes << ':' << setw(2) << seconds << endl;
    return 0;
}
```

`n % 3600` არის საათების გამოკლების შემდეგ დარჩენილი წამები; მათი 60-ზე გაყოფა გვაძლევს წუთებს. `setw(2)` მოქმედებს მხოლოდ მომდევნო გამოტანაზე, ამიტომ ის ყოველ რიცხვამდე ვიმეორებთ, `setfill('0')` კი ძალაში რჩება.
