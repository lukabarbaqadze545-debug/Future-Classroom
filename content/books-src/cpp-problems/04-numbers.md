# თავი 4. ციფრები და რიცხვთა თეორიის საფუძვლები
weeks: 3, 7

ამ თავის ამოცანები რიცხვებს „ხსნიან“: ციფრებად, გამყოფებად, მარტივ მამრავლებად. პროგრამა მცირე ხრიკებს იყენებს: `% 10` და `/ 10` ციფრებისთვის, ევკლიდეს ალგორითმი საერთო გამყოფისთვის, `i * i <= n` მიჯნა გამყოფების ძიებისთვის. შეზღუდვები აქ დიდია (10¹⁸), ამიტომ **ეფექტურობაც** მნიშვნელოვანია: ზოგი მარტივი მიდგომა ძალიან ნელი იქნებოდა.

წინაპირობა: ციკლები (`while`, `for`) და `long long`. თუ ამოცანა შეზღუდვაში 10¹²-ს ახსენებს, `n`-მდე ციკლი (ტრილიონი ნაბიჯი) არ გამოგადგებათ; მოძებნეთ მეთოდი, რომელიც ბევრად ნაკლებ ნაბიჯს მოითხოვს.

### მინიშნებები

1. როგორ მიიღებთ რიცხვის ბოლო ციფრს? როგორ „მოაჭრით“ მას?
2. ბოლო ციფრი: `n % 10`. ბოლო ციფრის მოჭრა: `n / 10`.
3. სანამ `n > 0`, დაუმატეთ `n % 10` ჯამს და შეცვალეთ `n` ის `n / 10`-ით. შეარჩიეთ `n`-ის ტიპი შეზღუდვის მიხედვით.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    cout << sum << endl;
    return 0;
}
```

ციკლი „ამოიღებს“ ციფრებს მარჯვნიდან მარცხნივ. `n = 0`-ზე ციკლი საერთოდ არ შესრულდება და პასუხია 0, რაც სწორია. ჯამი `int`-ია, რადგან ციფრების ჯამი 19 · 9-ზე მეტი ვერ იქნება.

### სტრესი

```brute
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int sum = 0;
    for (char c : s) sum += c - '0';
    cout << sum << endl;
    return 0;
}
```

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    int digits = 0;
    while (n > 0) {
        n /= 10;
        digits++;
    }
    cout << digits << endl;
    return 0;
}
```

ეს არის წინა ამოცანის ვარიანტი: ჯამის ნაცვლად ვითვლით ციფრებს. პირობაში `n ≥ 1`, ამიტომ პასუხი 0 არასოდეს იქნება. ამოცანაში 0 რომ დაშვებული ყოფილიყო, ცალკე შემთხვევა დაგვჭირდებოდა (ერთი ციფრია).

### მინიშნებები

1. წინა ამოცანის ციფრთა ჯამი აქ უნდა გაიმეოროთ.
2. გარე ციკლი მუშაობს, სანამ რიცხვი 9-ზე მეტია; შიდა ციკლი ითვლის ციფრთა ჯამს.
3. დაწერეთ გარე `while (n >= 10)` და მასში ციფრების ჯამის გამოთვლა, რომლის შედეგს `n`-ში ჩაწერთ.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    while (n >= 10) {
        long long sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }
        n = sum;
    }
    cout << n << endl;
    return 0;
}
```

ორი ჩადგმული ციკლი: შიდა ერთ „ზედაპირულ“ ჯამს ითვლის, გარე იმეორებს. პირველივე ჯამის შემდეგ რიცხვი ძალიან პატარაა (≤ 162), ამიტომ გარე ციკლი მხოლოდ რამდენჯერმე გაეშვება. არსებობს ფორმულა `1 + (n - 1) % 9`, რომელიც ციკლის გარეშე იგივეს იძლევა: სცადეთ დაამტკიცოთ.

### მინიშნებები

1. ციფრების გამოყოფას გახსოვთ ათობითში: ნაშთი და გაყოფა 10-ზე. რით შეცვლით 10-ს?
2. ორობითში ბოლო ციფრი არის `n % 2`, შემდეგ `n /= 2`. ციფრები ისე ამოდის, რომ ბოლოდან იწყება.
3. ჩაწერეთ ციფრები სტრიქონში და ბოლოს შეატრიალეთ (`reverse`). ცალკე იფიქრეთ `n = 0`-ზე.

### ამოხსნა

```cpp
#include <algorithm>
#include <iostream>
#include <string>
using namespace std;

int main() {
    long long n;
    cin >> n;
    string s;
    if (n == 0) {
        s = "0";
    }
    while (n > 0) {
        s += char('0' + n % 2);
        n /= 2;
    }
    reverse(s.begin(), s.end());
    cout << s << endl;
    return 0;
}
```

ნაშთები გამოდის უმცირესი თანრიგიდან უმაღლესისკენ, ამიტომ ჩაწერის შემდეგ ვაბრუნებთ. `char('0' + n % 2)` ციფრს (0 ან 1) სიმბოლოდ გარდაქმნის. `n = 0`-ზე ციკლი არ შესრულდება, ამიტომ ეს შემთხვევა ცალკეა.

1. პალინდრომი ტოლია საკუთარი „სარკისებური ასლის“.
2. წინა ამოცანაში შებრუნებული რიცხვი უკვე ააგეთ. შეადარეთ საწყისს.
3. შეინახეთ საწყისი რიცხვი ცალკე, შეატრიალეთ ასლი და შეადარეთ. 10-ის შემთხვევაში შებრუნებული რიცხვი 1 გამოვა, ამიტომ პასუხი `NO`-ა.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    long long rest = n, reversed = 0;
    while (rest > 0) {
        reversed = reversed * 10 + rest % 10;
        rest /= 10;
    }
    cout << (reversed == n ? "YES" : "NO") << endl;
    return 0;
}
```

ყურადღება მიაქციეთ: საწყისი რიცხვი `n` უნდა დარჩეს, რომ ბოლოს შევადაროთ, ამიტომ შებრუნება `rest`-ზე ხდება. რიცხვი, რომელიც ნულით მთავრდება (10, 120), პალინდრომი არ შეიძლება იყოს, რადგან მისი შებრუნებული წინა ნულებს დაკარგავს.

## უდიდესი საერთო გამყოფი

### მინიშნებები

1. ყველა რიცხვის გადარჩევა 10¹⁸-მდე შეუძლებელია. ეძებეთ უფრო ჭკვიანი გზა.
2. თუ `a = b · q + r`, მაშინ `gcd(a, b) = gcd(b, r)`. ეს ორი რიცხვის „დაპატარავების“ საშუალებას გვაძლევს.
3. გაიმეორეთ: `(a, b) → (b, a % b)` სანამ `b` არ გახდება 0. მაშინ `a` არის პასუხი.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }
    cout << a << endl;
    return 0;
}
```

ევკლიდეს ალგორითმი ყოველ ნაბიჯზე რიცხვებს სწრაფად ამცირებს: ორი ნაბიჯის შემდეგ ერთი რიცხვი, სულ მცირე, ნახევრად მცირდება. ამიტომ 10¹⁸-ზე ნაბიჯები რამდენიმე ათეულია და არა მილიარდები. `a < b` შემთხვევაც სწორად მუშაობს: პირველივე ნაბიჯი რიცხვებს ადგილს უცვლის.

1. უმცირეს საერთო ჯერადს უდიდესი საერთო გამყოფი უკავშირდება: `gcd(a, b) · lcm(a, b) = a · b`.
2. ჯერ გამოთვალეთ `gcd` (წინა ამოცანის ალგორითმით), შემდეგ გამოსახეთ `lcm`.
3. `lcm = a / gcd * b`: ჯერ გაყავით, მერე გაამრავლეთ, რომ შუალედური რიცხვი ზედმეტად არ გაიზარდოს. გამოიყენეთ `long long`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

long long gcd(long long a, long long b) {
    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}

int main() {
    long long a, b;
    cin >> a >> b;
    cout << a / gcd(a, b) * b << endl;
    return 0;
}
```

პასუხი 10¹⁸-მდეა და `long long`-ში ეტევა. `a / gcd * b` იგივე რიცხვია, რაც `a * b / gcd`, მაგრამ გაყოფა ჯერ ხდება, ამიტომ შუალედური ნამრავლი უფრო მცირეა და გადავსებას თავიდან ვიცილებთ. ფუნქცია `gcd` აქ პირველად გამოვიყენეთ; ფუნქციებს მეხუთე თავში დაწვრილებით გავივლით.

```brute
#include <iostream>
using namespace std;

int main() {
```

```cpp
        if (n % d == 0) {
            count += (d * d == n) ? 1 : 2;
        }
    }
    cout << count << endl;
    return 0;
}
```

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<bool> isPrime(n + 1, true);
    int count = 0;
    for (int p = 2; p <= n; p++) {
        if (!isPrime[p]) continue;
        count++;
        for (long long m = (long long)p * p; m <= n; m += p) {
            isPrime[m] = false;
        }
    }
    cout << count << endl;
    return 0;
}
```

როდესაც `p` ჯერ კიდევ „არ არის გადახაზული“, ეს ნიშნავს, რომ მას წინა მარტივი რიცხვები არ ჰყოფს, ანუ ის მარტივია. ჯერადების ხაზვა `p * p`-დან იწყება, რადგან უფრო პატარა ჯერადები უკვე გადახაზულია. `(long long)p * p` გადავსებას ერიდება, როცა `p` დიდია.

### მინიშნებები

1. 10¹⁸-მდე ყველა რიცხვის შემოწმება შეუძლებელია. იფიქრეთ, რას ითვლით ზუსტად?
2. რამდენი სრული კვადრატია `n`-მდე? ზუსტად იმდენი, რამდენი მთელი `k` აკმაყოფილებს `k² ≤ n`. ეს `⌊√n⌋`-ია.
3. `sqrtl` შეიძლება ცოტა გაცდეს მხოლოდ ათწილადის სიზუსტის გამო. გამოიყენეთ იგი როგორც სავარაუდო პასუხი, შემდეგ შეასწორეთ მცირე ციკლებით: `while (r * r > n) r--; while ((r + 1) * (r + 1) <= n) r++;`.

### ამოხსნა

```cpp
#include <cmath>
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    long long r = (long long)sqrtl((long double)n);
    while (r * r > n) {
        r--;
    }
    while ((r + 1) * (r + 1) <= n) {
        r++;
    }
    cout << r << endl;
    return 0;
}
```

ათწილადი კვადრატული ფესვი დიდ რიცხვებზე ერთით შეიძლება აცდეს. ორი მცირე ციკლი ამას ასწორებს მთელი რიცხვების ზუსტი შედარებით. `(r + 1) * (r + 1)` მაქსიმუმ დაახლოებით 10¹⁸-ია და `long long`-ში ეტევა. ზოგადი წესი: ათწილადით მიახლოებული ნაპოვნია, მთელი რიცხვებით გადამოწმებული.

### სტრესი

```brute
}
```

## ხარისხი მოდულით
level: 4
tags: სწრაფი ხარისხი, %, long long, ეფექტურობა

გამოთვალეთ `aᵇ mod m`, ანუ `a`-ს `b`-ური ხარისხის ნაშთი `m`-ზე გაყოფისას.

### შეყვანა

ერთ ხაზზე სამი მთელი რიცხვი `a`, `b`, `m`.

### გამოტანა

ერთი რიცხვი: `aᵇ mod m`.

### შეზღუდვები

1 ≤ a ≤ 10⁹, 0 ≤ b ≤ 10¹⁸, 2 ≤ m ≤ 10⁹

### მაგალითი

```in
2 10 1000
```

```out
24
```

### განმარტება

2¹⁰ = 1024, ნაშთი 1000-ზე გაყოფისას 24-ია.

### მაგალითი


```out

```



### მინიშნებები

1. `b` 10¹⁸-მდეა, ამიტომ `b` ჯერ გამრავლება შეუძლებელია. ხარისხი უფრო სწრაფად უნდა გამოითვალოს.
2. `aᵇ = (a²)^(b/2)`, თუ `b` ლუწია; და `a · aᵇ⁻¹`, თუ კენტია. `b` ნახევრდება და ბიჯები 60-მდე იკლებს.
3. შეინახეთ `result` (საწყისად 1) და `base = a % m`. სანამ `b > 0`: თუ `b` კენტია, `result = result * base % m`; `base = base * base % m`; `b /= 2`. ყოველი გამრავლების შემდეგ ნაშთი აიღეთ, რომ რიცხვები 10¹⁸-ს არ აღემატებოდეს.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    long long a, b, m;
    cin >> a >> b >> m;
    long long result = 1;
    long long base = a % m;
    while (b > 0) {
        if (b % 2 == 1) {
            result = result * base % m;
        }
        base = base * base % m;
        b /= 2;
    }
    cout << result << endl;
    return 0;
}
```

ეს „ორობითი ხარისხი“ ერთ-ერთი ყველაზე ხშირად გამოყენებადი ხრიკია: `b`-ს ორობით ჩანაწერში ყოველი ერთიანი ციფრისთვის ერთხელ ვამრავლებთ. ნაბიჯები `b`-ს ორობით სიგრძეს უტოლდება, მაქსიმუმ 60. ყოველი გამრავლების შემდეგ `% m` იღებთ, ამიტომ რიცხვები `m² ≤ 10¹⁸`-ს არ აღემატება და `long long`-ში ეტევა.

### სტრესი

```brute
#include <iostream>
using namespace std;

int main() {
    long long a, b, m;
    cin >> a >> b >> m;
    long long result = 1 % m;
    for (long long i = 0; i < b; i++) {
        result = result * (a % m) % m;
    }
    cout << result << endl;
    return 0;
}
```
