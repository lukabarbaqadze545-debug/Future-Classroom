# დანართი. მოკლე ცნობარი

ეს დანართი ამოცანების ამოხსნისას გამოგადგებათ: საწყისი პროგრამა, ტიპების ზღვრები, ბიბლიოთეკის ფუნქციები, დროის შეფასება და ხშირი შეცდომების სია. ეს ცნობარია და არა სახელმძღვანელო: ახსნა სახელმძღვანელოში ან მასწავლებელთან მოძებნეთ.

## საწყისი პროგრამა

ყველა ამოცანას ამ ჩარჩოდან შეგიძლიათ დაიწყოთ:

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    // ამოხსნა
    return 0;
}
```

სტრიქონები `ios::sync_with_stdio(false)` და `cin.tie(nullptr)` შეყვანას ბევრად აჩქარებს, როცა რიცხვები 10⁵-ზე მეტია. ისინი ერთხელ და `main`-ის დასაწყისში დაწერეთ. თუ ამ ხაზებს იყენებთ, `cin` და `scanf` ერთად ნუ გამოიყენებთ.

## ტიპები და მათი ზღვრები

- `int`: დაახლოებით ±2,1 · 10⁹ (ზუსტად 2147483647).
- `long long`: დაახლოებით ±9,2 · 10¹⁸.
- `unsigned int`, `unsigned long long`: მხოლოდ არაუარყოფითი, ზღვარი ორჯერ მეტია; გადავსებისას იწყება თავიდან.
- `double`: დაახლოებით 15 მნიშვნელოვანი ციფრი; ათწილადები მიახლოებითია.
- `char`: ერთი სიმბოლო, რიცხვიც არის (კოდი 0–127 ასოებისთვის: `'0'` = 48, `'A'` = 65, `'a'` = 97).
- `bool`: `true` ან `false`.
- `size_t`: ბიბლიოთეკების ზომების ტიპი (უნიშნო); `s.size() - 1` ცარიელ სტრიქონზე უზარმაზარი რიცხვია.

წესი: ჯერ შეზღუდვებით გამოთვალეთ მაქსიმალური პასუხი და შემდეგ აარჩიეთ ტიპი. თუ ორი რიცხვის ნამრავლი ან ჯამი `int`-ს აღემატება, გამოიყენეთ `long long` **ცვლადის გამოცხადებისას**: გამოთვლა ტიპს არ ცვლის.

## შეყვანა და გამოტანა

- `cin >> a >> b;` წაიკითხავს ორ მნიშვნელობას ინტერვალებით.
- `while (cin >> x)` კითხულობს, სანამ შეყვანა არ ამოიწურება.
- `getline(cin, s)` კითხულობს მთელ ხაზს; `cin >> n`-ის შემდეგ ჯერ `cin.ignore()`.
- `cout << x << "\n";`: `"\n"` უფრო სწრაფია, ვიდრე `endl` (ბუფერს გამოცლის).
- `#include <iomanip>`: `fixed << setprecision(2)` არის ორი ციფრი წერტილის შემდეგ; `setw(2) << setfill('0')` გვაძლევს წინა ნულებს.

## სტრიქონები

- `s.size()`, `s[i]`, `s.substr(from, length)`, `s.find(t)` (შედეგი `string::npos`, თუ არ არის), `s += t`, `s.push_back(c)`, `s.pop_back()`.
- `to_string(x)`: რიცხვი სტრიქონად. `stoi(s)`, `stoll(s)`: სტრიქონი რიცხვად.
- `reverse(s.begin(), s.end())`, `sort(s.begin(), s.end())`.
- `<cctype>`: `isdigit(c)`, `isalpha(c)`, `isupper(c)`, `islower(c)`, `toupper(c)`, `tolower(c)`.

## ფუნქციები `<algorithm>`-დან

- `sort(a.begin(), a.end())`; კლებადობით: `sort(a.begin(), a.end(), greater<int>())`.
- `reverse`, `min`, `max`, `swap`, `min_element`, `max_element`.
- `binary_search`, `lower_bound`, `upper_bound`: მხოლოდ დახარისხებულ მასივზე.
- `unique` (მეზობელი ერთნაირების მოშორება, ჩვეულებრივ დახარისხების შემდეგ).
- `next_permutation(a.begin(), a.end())`: შემდეგი გადანაცვლება; დაიწყეთ დახარისხებულიდან.
- `iota(a.begin(), a.end(), 1)` (`<numeric>`): ავსებს 1, 2, 3, …

## სტრუქტურები და მათი ღირებულება

- `vector`: `push_back` და წვდომა `a[i]` ინდექსით ძალიან სწრაფია; დასაწყისში ჩასმა `O(n)`.
- `stack`, `queue`, `deque`: ჩასმა/ამოღება ბოლოებიდან `O(1)`.
- `set`, `map`: ძებნა, ჩასმა, წაშლა `O(log n)`; ელემენტები დახარისხებულია.
- `priority_queue`: უდიდესი ელემენტის ამოღება `O(log n)`; უმცირესისთვის `greater`-ით.
- `pair<A, B>`, `struct`: რამდენიმე მნიშვნელობა ერთად.

## რა სირთულე გამოდგება

კომპიუტერი წამში დაახლოებით 10⁸ მარტივ ოპერაციას ასრულებს. შეზღუდვის მიხედვით:

- `n ≤ 10`: `n!`.
- `n ≤ 20`: `2ⁿ`.
- `n ≤ 300`: `n³`.
- `n ≤ 5000`: `n²`.
- `n ≤ 10⁶`: `n` ან `n log n`.
- `n ≤ 10¹⁸`: `log n` ან ფორმულა.

თუ ორ მეთოდს შორის ვერ გადაწყვიტეთ, დათვალეთ ოპერაციათა რაოდენობა ზღვრულ ტესტზე და შეადარეთ 10⁸-ს.

## ხშირი შეცდომები: შემოწმების სია

ამოხსნის დასრულებამდე გაიარეთ ეს სია:

1. **ერთით შეცდომა.** `i < n` თუ `i <= n`? ინდექსი 0-დან იწყება თუ 1-დან? შეამოწმეთ ციკლი პირველ და ბოლო ბიჯზე.
2. **გადავსება.** შუალედური ნამრავლი ან ჯამი `int`-ს აღემატება? ჯამის ცვლადი `long long`-ია?
3. **მთელი გაყოფა.** `7 / 2` არის 3. საჭიროა ათწილადი: `7 / 2.0`.
4. **ნაშთი უარყოფითზე.** `-3 % 2` არის `-1`. თუ ყოველთვის არაუარყოფითი ნაშთი გინდათ: `((x % m) + m) % m`.
5. **ცვლადი არ არის განულებული.** განსაკუთრებით რამდენიმე ტესტის შემთხვევაში: ცვლადები ტესტის დასაწყისში გამოაცხადეთ.
6. **`=` და `==`.** პირობაში `=` შემთხვევით არ დაგრჩეთ. კომპილატორის გაფრთხილებებს მიაქციეთ ყურადღება.
7. **ნულზე გაყოფა და ცარიელი სტრუქტურა.** `front()` ცარიელ რიგზე, `a[0]` ცარიელ მასივზე.
8. **მასივის საზღვრები.** `a[n]` მასივიდან გასვლაა. გამართვისას ააგეთ `-fsanitize=address,undefined`-ით.
9. **ზღვრული შემთხვევები.** `n = 1`, ყველა ელემენტი ერთნაირია, ყველა უარყოფითია, მინიმალური და მაქსიმალური მნიშვნელობა.
10. **გამოტანის ფორმატი.** ზედმეტი ტექსტი, ხაზის გადატანა, ათწილადის ციფრები.
11. **რეკურსიის სიღრმე.** 10⁵-ზე ღრმა რეკურსია სტეკს გადაავსებს: გამოიყენეთ ციკლი ან `stack`/`queue`.
12. **შედარების ფუნქცია `sort`-ისთვის.** ის მკაცრი უნდა იყოს (`<`, `>` და არა `<=`, `>=`).

## გამართვის ხერხები

- **გამოიტანეთ შუალედური მნიშვნელობები** `cerr`-ით (ის შეფასებულ გამოტანაში არ ხვდება).
- **ხელით გაიარეთ** მცირე ტესტი ცხრილში: ცვლადების მნიშვნელობები ყოველი ნაბიჯის შემდეგ.
- **შეამცირეთ ტესტი**, სანამ შეცდომა ჯერ კიდევ გამოჩნდება: პატარა ტესტზე ცხადია, სად გადაუხვიეთ.
- **დაწერეთ ნელი, მაგრამ აშკარად სწორი ამოხსნა** (სრული გადარჩევა) და შეადარეთ თქვენს სწრაფ ამოხსნას შემთხვევით ტესტებზე.

## სტრესტესტი: ორი ამოხსნის შედარება

ეს მეთოდი გამოიყენება ამ წიგნის ამოხსნების შესამოწმებლადაც, სადაც ამას აზრი ჰქონდა. თქვენც შეგიძლიათ. დაგჭირდებათ: `sol.cpp` (სწრაფი ამოხსნა), `brute.cpp` (ნელი, სწორი ამოხსნა) და `gen.py` (იღებს ნომერს, ბეჭდავს შემთხვევით პატარა ტესტს).

```text
g++ -std=c++17 -O2 -o sol sol.cpp
g++ -std=c++17 -O2 -o brute brute.cpp
for i in $(seq 1 200); do
  python3 gen.py $i > in.txt
  ./sol < in.txt > out1.txt
  ./brute < in.txt > out2.txt
  diff -q out1.txt out2.txt > /dev/null || { echo "განსხვავება ტესტზე $i"; break; }
done
```

თუ ციკლი გაჩერდა, `in.txt` შეიცავს ტესტს, რომელზეც ორი პროგრამა განსხვავდება. მისი შესწავლით ეძებეთ შეცდომა: ეს ყველაზე სწრაფი გზაა იმ შეცდომისკენ, რომელიც მაგალითებზე არ ჩანს.

`gen.py`-ს მაგალითი ორი რიცხვისთვის:

```text
import random, sys
random.seed(int(sys.argv[1]))
print(random.randint(1, 20), random.randint(1, 20))
```
