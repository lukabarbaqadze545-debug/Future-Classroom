# თავი 9. ვარაუდი და შეცდომის პოვნა
weeks: 6

პროგრამისტი დროის დიდ ნაწილს ამ ორ საქმეს უთმობს: ამოიკითხოს, რას აკეთებს კოდი, და იპოვოს, რატომ არ აკეთებს იმას, რასაც უნდა. ამ თავში ამოცანები ორი სახისაა.

**ვარაუდი.** მოცემულია მზა პროგრამა. თქვენ უნდა გამოთვალოთ, **რას დაბეჭდავს** ის, მისი გაშვების გარეშე. ეს ავითარებს „ხელით შესრულების“ უნარს, რომელიც გამართვისას (დებაგისას) ყველაზე მეტად გჭირდებათ. ჩაიწერეთ ცვლადების მნიშვნელობები ცხრილში ყოველი ნაბიჯის შემდეგ და მხოლოდ მერე გაუშვით პროგრამა შესამოწმებლად.

**შეცდომის პოვნა.** მოცემულია პროგრამა, რომელიც არასწორად მუშაობს. აღწერილია, რა უნდა აკეთოს, და ნაჩვენებია მაგალითი, რომელზეც ის ცდება. იპოვეთ შეცდომა, აგიხსენით მიზეზი და გაასწორეთ. ჯერ გაუშვით პროგრამა მაგალითზე და ნახეთ, რას დაბეჭდავს, მხოლოდ მერე ეძებეთ მიზეზი.

წინაპირობა: წინა თავები. ამ თავში „სწორი პასუხი“ ყოველთვის მოცემულია, ამიტომ მნიშვნელოვანია პროცესი: ჯერ ჰიპოთეზა, მერე გამოცდა.

## ციკლი და continue
level: 1
kind: predict
tags: ვარაუდი, for, continue

რას დაბეჭდავს ეს პროგრამა?

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) {
            continue;
        }
        sum += i;
    }
    cout << sum << endl;
    return 0;
}
```

### მინიშნებები

1. `continue` ციკლის მიმდინარე ბიჯს წყვეტს და მომდევნოზე გადადის.
2. რომელი `i`-ები გადაიტოვებს პროგრამა 1-დან 10-მდე?

### ამოხსნა

```out
37
```

3-ზე გაყოფადი რიცხვები (3, 6, 9) არ ემატება ჯამს. 1 + … + 10 = 55, 55 − (3 + 6 + 9) = 37.

## მთელი და ათწილადი გაყოფა
level: 1
kind: predict
tags: ვარაუდი, ტიპები, /

რას დაბეჭდავს ეს პროგრამა?

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7, b = 2;
    double x = a / b;
    double y = (double)a / b;
    cout << x << " " << y << endl;
    return 0;
}
```

### მინიშნებები

1. რას გვაძლევს `7 / 2`, როცა ორივე რიცხვი `int` ტიპისაა?
2. გაყოფა პირველ შემთხვევაში მთელზე სრულდება და მხოლოდ შემდეგ ინახება `double`-ში.

### ამოხსნა

```out
3 3.5
```

`a / b` ორივე `int`-ია, ამიტომ შედეგი 3-ია (წილადი ნაწილი იკარგება) და `double`-ად გარდაიქმნება მხოლოდ შენახვისას. `(double)a / b` ჯერ `a`-ს ათწილადად აქცევს, ამიტომ გაყოფა ზუსტია: 3,5. `cout` ათწილადს უსარგებლო ნულების გარეშე აბეჭდავს.

## ციკლი ნაბიჯით 2
level: 1
kind: predict
tags: ვარაუდი, while, ცვლადები

რას დაბეჭდავს ეს პროგრამა?

```cpp
#include <iostream>
using namespace std;

int main() {
    int i = 5, s = 0;
    while (i > 0) {
        s += i;
        i -= 2;
    }
    cout << s << " " << i << endl;
    return 0;
}
```

### მინიშნებები

1. ჩაწერეთ ცხრილში `i` და `s` ყოველი ბიჯის შემდეგ.
2. გაითვალისწინეთ, რომ ციკლის შემდეგ `i`-ს აქვს ის მნიშვნელობა, რომლისთვისაც პირობა მცდარი გახდა.

### ამოხსნა

```out
9 -1
```

ბიჯები: `i = 5`: `s = 5`, `i = 3`; `i = 3`: `s = 8`, `i = 1`; `i = 1`: `s = 9`, `i = -1`. პირობა `i > 0` მცდარია, ციკლი მთავრდება. ბეჭდავს `s` და `i`: `9 -1`.

## სიმბოლოები და კოდები

```cpp
#include <iostream>
```

### ამოხსნა

```out
d 100 D
```

`'a' + 3` არის 100, ანუ სიმბოლო `'d'`. `(int)c` აჩვენებს მის კოდს: 100. `c - 32` არის 68, ანუ `'D'`: დიდი ასოები პატარებზე 32-ით ნაკლები კოდებით არის განლაგებული.

## ორი ციკლი და break
level: 2
kind: predict
tags: ვარაუდი, ჩადგმული ციკლები, break

რას დაბეჭდავს ეს პროგრამა?

```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 0;
    for (int i = 1; i <= 4; i++) {
        for (int j = 1; j <= 4; j++) {
            if (j > i) {
                break;
            }
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

### მინიშნებები

1. `break` მხოლოდ შიდა ციკლს წყვეტს.
2. ყოველი `i`-სთვის დათვალეთ, რამდენჯერ შესრულდება `count++`.

### ამოხსნა

```out
10
```

`i = 1`-ზე შიდა ციკლი ერთხელ ზრდის `count`-ს (`j = 1`), `j = 2` უკვე `j > i` პირობას ეჯახება. `i = 2`-ზე ორჯერ, `i = 3`-ზე სამჯერ, `i = 4`-ზე ოთხჯერ: 1 + 2 + 3 + 4 = 10.

## ფუნქცია და მიმართვა

```cpp
#include <iostream>
using namespace std;

void f(int a, int &b) {
    a++;
    b++;
}

int main() {

    cout << x << " " << y << endl;

```

### მინიშნებები

1. რომელი პარამეტრი გადაიცემა ასლით და რომელი მიმართვით?

### ამოხსნა

```out
1 3
```

`a` არის `x`-ის ასლი, ამიტომ `a++` `x`-ს არ ცვლის და `x` რჩება 1. `b` არის `y`-ის მიმართვა (`&`), ამიტომ `b++` უშუალოდ `y`-ს ზრდის: ორი გამოძახების შემდეგ `y = 3`.

## ერთი უწყვეტი გავლა
level: 2
kind: predict
tags: ვარაუდი, მასივი, swap

რას დაბეჭდავს ეს პროგრამა?

```cpp
#include <iostream>
#include <utility>
using namespace std;

int main() {
    int a[5] = {5, 3, 8, 1, 9};
    for (int i = 0; i < 4; i++) {
        if (a[i] > a[i + 1]) {
            swap(a[i], a[i + 1]);
        }
    }
    for (int i = 0; i < 5; i++) {
        cout << a[i] << " ";
    }
    cout << endl;
    return 0;
}
```

### მინიშნებები

1. ჩაიწერეთ მასივი ყოველი `swap`-ის შემდეგ.
2. პროგრამა მასივს ერთხელ გადის: ის ბუშტუკოვანი დახარისხების ერთი ნაბიჯია, მაგრამ სრულად არ ალაგებს.

### ამოხსნა

```out
3 5 1 8 9
```

ბიჯები: `[5 3 8 1 9]` → (5 > 3) გაცვლა → `[3 5 8 1 9]` → (5 > 8?) არა → (8 > 1) გაცვლა → `[3 5 1 8 9]` → (8 > 9?) არა. ერთი გავლა უდიდეს ელემენტს ბოლოში ტოვებს, მაგრამ 1 ჯერ კიდევ არასწორ ადგილზეა: სრული დახარისხებისთვის გავლები უნდა გამეორდეს.

### მინიშნებები

1. გაუშვით პროგრამა მაგალითზე და ნახეთ, რას აბრუნებს. რას ამბობს კომპილატორი გაფრთხილებებში (`-Wall`)?
2. C++-ში `=` ნიშნავს მინიჭებას, `==` კი შედარებას.
3. პირობაში `n = 10` პირველ რიგში `n`-ს ანიჭებს 10-ს, შემდეგ კი შედეგს (10, ანუ ჭეშმარიტს) პირობად იყენებს. ამიტომ პროგრამა ყოველთვის `YES`-ს ბეჭდავს.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n == 10) {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
    return 0;
}
```

შეცდომა: `if (n = 10)` მინიჭებაა და არა შედარება. ის `n`-ს ცვლის და ყოველთვის ჭეშმარიტია, რადგან 10 არ არის ნული. კომპილატორი ამას გაფრთხილებით გვაცნობებს (`-Wall`-ით: „suggest parentheses around assignment used as truth value“): ამიტომ გაფრთხილებებს ყოველთვის ჩართეთ და წაიკითხეთ. ზოგი პროგრამისტი შედარებას ასე წერს: `10 == n`; შემთხვევით `=` რომ გამოეტოვებინათ, კომპილატორი შეცდომას დაწერდა.

3. `sum` ციკლის გარეთაა გამოცხადებული, ამიტომ ტესტებს შორის მისი მნიშვნელობა არ ნულდება.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        long long sum = 0;
        for (int i = 0; i < n; i++) {
            int x;
            cin >> x;
            sum += x;
        }
        cout << sum << endl;
    }
    return 0;
}
```

ცვლადი უნდა გამოვაცხადოთ ან განვაულოთ **იქ, სადაც ახალი საქმე იწყება**: აქ ყოველ ტესტზე. როცა ცვლადი ციკლის გარეთაა, ის წინა ტესტის მნიშვნელობას ინახავს. ეს ერთ-ერთი ყველაზე ხშირი შეცდომაა ოლიმპიადებზე, სადაც ერთ ფაილში მრავალი ტესტია.
