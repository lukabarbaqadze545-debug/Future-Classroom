# თავი 5. ფუნქციები
weeks: 4

ფუნქცია პროგრამის ნაწილს სახელს აძლევს: დიდ ამოცანას ვჭრით პატარა, გასაგებ ნაწილებად. ამ თავში ვივარჯიშებთ ფუნქციის დაწერაში (პარამეტრები, დასაბრუნებელი მნიშვნელობა, `void`), გადაცემაში მნიშვნელობით და მიმართვით (`&`), და დიდი ამოცანის დაშლაში.

პროგრამა ამ თავშიც სტანდარტულ შეყვანა-გამოტანას იყენებს. პირობაში ფუნქციის სახელი და მისი დანიშნულებაა მოცემული, ხოლო `main` იძახებს მას. სახელები რომ შეარჩიოთ სხვანაირად, ეს ხელს არ შეუშლის ამოცანას, მაგრამ ფუნქციის გამოყენება მაინც სასურველია: თქვენი მიზანი სწორედ ამის სწავლაა.

## კვირის დღე
level: 1
tags: ფუნქცია, string, switch, %

დღეს ორშაბათია. დაწერეთ ფუნქცია `string dayName(int d)`, რომელიც დღის ნომერს (0 — Monday, 1 — Tuesday, … 6 — Sunday) დღის სახელად გარდაქმნის. გამოიყენეთ იგი, რომ გამოიტანოთ, რომელი დღე იქნება `n` დღის შემდეგ.

### მინიშნებები

1. კვირის დღეები ყოველ 7 დღეში მეორდება. რა მოქმედება ინახავს „ციკლის ადგილს“?
2. `n % 7` იძლევა ნომერს 0-დან 6-მდე.
3. `dayName` აბრუნებს სახელს ნომრით (`switch` ან სტრიქონების მასივი). `main` კითხულობს `n`-ს და გამოიტანს `dayName(n % 7)`.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

string dayName(int d) {
    switch (d) {
        case 0: return "Monday";
        case 1: return "Tuesday";
        case 2: return "Wednesday";
        case 3: return "Thursday";
        case 4: return "Friday";
        case 5: return "Saturday";
        default: return "Sunday";
    }
}

int main() {
    int n;
    cin >> n;
    cout << dayName(n % 7) << endl;
    return 0;
}
```

ფუნქცია აბრუნებს მნიშვნელობას `return`-ით და `main` ამ მნიშვნელობას პირდაპირ გამოიტანს. ფუნქციის ყველა გზა `return`-ით უნდა მთავრდებოდეს, ამიტომ `default` დაგვჭირდა: ის დარჩენილ 6-ს ფარავს.

## სამკუთხედის ფართობი
level: 2
tags: ფუნქცია, double, sqrt, გამოტანის ფორმატი

სამკუთხედის ფართობი გვერდებიდან ჰერონის ფორმულით გამოითვლება: თუ `p = (a + b + c) / 2`, მაშინ `S = √(p · (p − a) · (p − b) · (p − c))`. დაწერეთ ფუნქცია `double area(double a, double b, double c)` და გამოიტანეთ ფართობი ორი ციფრით წერტილის შემდეგ.

### შეყვანა

### მინიშნებები

1. ფორმულა შედგება ორი ნაბიჯისგან: ნახევარპერიმეტრი და ფესვი ნამრავლიდან.
2. კვადრატული ფესვისთვის გამოიყენეთ `sqrt` ბიბლიოთეკიდან `<cmath>`.
3. ფუნქციაში გამოთვალეთ `p`, შემდეგ დააბრუნეთ `sqrt(p * (p - a) * (p - b) * (p - c))`. გამოსატანად `fixed << setprecision(2)`.

### ამოხსნა

```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
using namespace std;

double area(double a, double b, double c) {
    double p = (a + b + c) / 2;
    return sqrt(p * (p - a) * (p - b) * (p - c));
}

int main() {
    double a, b, c;
    cin >> a >> b >> c;
    cout << fixed << setprecision(2) << area(a, b, c) << endl;
    return 0;
}
```

ფუნქციის შიგნით დამოუკიდებელი ცვლადებია: `p` მხოლოდ `area`-ში არსებობს. პროგრამის ამ ნაწილის შეკრება `main`-ში ამოხსნას გააადვილებს: ფუნქციას ცალკე შეამოწმებთ.

## მანძილი წერტილებს შორის

tags: ფუნქცია, double, sqrt, გეომეტრია

დაწერეთ ფუნქცია `double dist(double x1, double y1, double x2, double y2)`, რომელიც ბრტყელ სიბრტყეზე ორ წერტილს შორის მანძილს გამოთვლის, და გამოიტანეთ პასუხი სამი ციფრით წერტილის შემდეგ.

### შეყვანა

### გამოტანა

### მინიშნებები

1. იფიქრეთ მართკუთხა სამკუთხედზე, რომლის კათეტები კოორდინატების სხვაობებია.
2. მანძილი არის `√((x₂ − x₁)² + (y₂ − y₁)²)`.
3. `sqrt(dx * dx + dy * dy)`, სადაც `dx = x2 - x1`, `dy = y2 - y1`. გამოსატანად `fixed << setprecision(3)`.

### ამოხსნა

```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
using namespace std;

double dist(double x1, double y1, double x2, double y2) {
    double dx = x2 - x1;
    double dy = y2 - y1;
    return sqrt(dx * dx + dy * dy);
}

int main() {
    double x1, y1, x2, y2;
    cin >> x1 >> y1 >> x2 >> y2;
    cout << fixed << setprecision(3) << dist(x1, y1, x2, y2) << endl;
    return 0;
}
```

მანძილი არის პითაგორას თეორემის პირდაპირი გამოყენება. ათწილადი რიცხვები მიახლოებითია: ერთი და იგივე წერტილისთვის ზუსტი 0 გამოდის, ხოლო წილად რიცხვებზე ბოლო ციფრები შეიძლება უმნიშვნელოდ განსხვავდებოდეს, ამიტომ გამოსატანი ციფრების რაოდენობა დაფიქსირებულია.

## წილადის შეკვეცა
level: 2
tags: ფუნქცია, gcd, წილადი

დაწერეთ ფუნქცია `long long gcd(long long a, long long b)` და მისი გამოყენებით შეკვეცეთ წილადი `a / b`.

### შეყვანა

ერთ ხაზზე ორი მთელი დადებითი რიცხვი `a` (მრიცხველი) და `b` (მნიშვნელი).

### გამოტანა

### შეზღუდვები

1 ≤ a, b ≤ 10¹⁸

### მაგალითი

```in
6 8
```

```out
3/4
```

### მაგალითი

```in
5 7
```

```out
5/7
```

### მაგალითი

```in

```

```out
10/1
```

### მინიშნებები

1. წილადი არ იკვეცება მაშინ, როცა მრიცხველსა და მნიშვნელს საერთო გამყოფი არ აქვთ.
2. იპოვეთ უდიდესი საერთო გამყოფი (ევკლიდე). წინა თავში ეს გააკეთეთ.
3. გაყავით ორივე რიცხვი `gcd(a, b)`-ზე და გამოიტანეთ `a / g << "/" << b / g`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

long long gcd(long long a, long long b) {
    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}

int main() {
    long long a, b;
    cin >> a >> b;
    long long g = gcd(a, b);
    cout << a / g << "/" << b / g << endl;
    return 0;
}
```

ფუნქცია `gcd` ჩვენ ერთხელ დავწერეთ და ახლა ერთ ადგილას გვაქვს. იგივე ფუნქცია გამოგადგებათ უმცირესი საერთო ჯერადის, წილადების შეკრებისა და სხვა ამოცანებისთვის: ეს დაშლისა და გამეორებული გამოყენების არსია.

### სტრესი

```brute
#include <iostream>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    long long g = 1;
    for (long long d = 1; d <= a && d <= b; d++) {
        if (a % d == 0 && b % d == 0) g = d;
    }
    cout << a / g << "/" << b / g << endl;
    return 0;
}
```

დაწერეთ ფუნქცია `void order(int &x, int &y)`, რომელიც `x`-სა და `y`-ს ისე გაცვლის, რომ `x ≤ y` იყოს. გამოიყენეთ იგი სამი რიცხვის ზრდადობით დასალაგებლად.

### მინიშნებები

1. თუ ფუნქციას ცვლადებს უბრალოდ გადასცემთ, ის მათ ასლებთან მუშაობს. რა უნდა გააკეთოთ, რომ ორიგინალი შეიცვალოს?
2. პარამეტრის წინ `&` აკეთებს მიმართვას: ფუნქცია ორიგინალ ცვლადს ცვლის.
3. `order(x, y)`: თუ `x > y`, გაცვალეთ. სამი რიცხვისთვის გამოიძახეთ `order(a, b)`, `order(b, c)`, `order(a, b)`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

void order(int &x, int &y) {
    if (x > y) {
        int t = x;
        x = y;
        y = t;
    }
}

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    order(a, b);
    order(b, c);
    order(a, b);
    cout << a << " " << b << " " << c << endl;
    return 0;
}
```

`&` გარეშე ფუნქცია მხოლოდ ასლს შეცვლიდა და `main`-ში არაფერი დალაგდებოდა. სამი ცვლადის დასალაგებლად სამი ნაბიჯი საკმარისია: პირველი ორი ნაბიჯი უდიდესს `c`-ში გადაიყვანს, მესამე `a`-სა და `b`-ს ალაგებს.

## რიცხვები მოცემული ციფრთა ჯამით
level: 2
tags: ფუნქცია, ციფრები, დათვლა

დაწერეთ ფუნქცია `int digitSum(int x)` და დათვალეთ, რამდენი რიცხვი `a`-დან `b`-მდე (ორივე ჩათვლით) აქვს ციფრთა ჯამი ზუსტად `s`.

### შეყვანა

ერთ ხაზზე სამი მთელი რიცხვი `a`, `b`, `s`.

### გამოტანა

ერთი რიცხვი: რაოდენობა.

### შეზღუდვები

1 ≤ a ≤ b ≤ 10⁶, 1 ≤ s ≤ 54

### მაგალითი

```in
1 100 5
```

```out
6
```

### განმარტება

ციფრთა ჯამი 5 აქვს რიცხვებს 5, 14, 23, 32, 41, 50.

### მაგალითი

```in
10 99 18
```

```out
1
```

### შემოწმება

```in
1 10 10
```

```out
0
```

### მინიშნებები

1. ორი სხვადასხვა საქმეა: ციფრთა ჯამის გამოთვლა და რიცხვების გადარჩევა.
2. ციფრთა ჯამი გამოთვალეთ ფუნქციაში (როგორც ადრე), ხოლო `main`-ში გაიარეთ `a`-დან `b`-მდე.
3. `for (x = a; x <= b; x++) if (digitSum(x) == s) count++;`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int digitSum(int x) {
    int sum = 0;
    while (x > 0) {
        sum += x % 10;
        x /= 10;
    }
    return sum;
}

int main() {
    int a, b, s;
    cin >> a >> b >> s;
    int count = 0;
    for (int x = a; x <= b; x++) {
        if (digitSum(x) == s) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

ციფრთა ჯამის გამოთვლა ფუნქციაში ამოიღეთ, ამიტომ `main` უფრო მოკლე და გასაგებია: „გაიარე რიცხვები, დაითვალე ისინი, ვისაც ჯამი `s`-ის ტოლი აქვს“. ეს დაშლის მარტივი სარგებელია.

### სტრესი

```brute
#include <iostream>
#include <string>
using namespace std;

int main() {
    int a, b, s;
    cin >> a >> b >> s;
    int count = 0;
    for (int x = a; x <= b; x++) {
        string t = to_string(x);
        int sum = 0;
        for (char c : t) sum += c - '0';
        if (sum == s) count++;
    }
    cout << count << endl;
    return 0;
}
```

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

bool isPrime(int n) {
    if (n < 2) {
        return false;
    }
    for (int d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            return false;
        }
    }
    return true;
}

int main() {
    int q;
    cin >> q;
    for (int i = 0; i < q; i++) {
        int n;
        cin >> n;
        cout << (isPrime(n) ? "YES" : "NO") << endl;
    }
    return 0;
}
```

```cpp
bool isPrime(int n) {
    if (n < 2) {
        return false;
```

```cpp
#include <iostream>
using namespace std;

int properSum(int x) {
    int sum = 0;
    for (int d = 1; d <= x / 2; d++) {
        if (x % d == 0) {
            sum += d;
        }
    }
    return sum;
}

int main() {
    int n;
    cin >> n;
    bool found = false;
    for (int x = 1; x <= n; x++) {
        if (properSum(x) == x) {
            if (found) cout << " ";
            cout << x;
            found = true;
        }
    }
    cout << (found ? "" : "NONE") << endl;
    return 0;
}
```

### მინიშნებები

1. ორი რიცხვის `gcd` გქონდათ. რამდენ რიცხვზე გაავრცელებთ?
2. `gcd(a, b, c) = gcd(gcd(a, b), c)`.
3. წაიკითხეთ პირველი რიცხვი `g`-ში; ყოველი შემდეგისთვის `g = gcd(g, x)`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

long long gcd(long long a, long long b) {
    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }
    return a;
}

int main() {
    int n;
    cin >> n;
    long long g = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        g = gcd(g, x);
    }
    cout << g << endl;
    return 0;
}
```

`gcd(0, x)` არის `x`: ამიტომ `g = 0`-დან დაწყება პირველ რიცხვსაც ზუსტად ამუშავებს და განსაკუთრებული შემთხვევა აღარ გვჭირდება. ნაკრების `gcd` არასოდეს გაიზრდება: ყოველ ახალ რიცხვზე ის ან იგივე რჩება, ან მცირდება.

3. შეინახეთ თვეების დღეები მასივში `{31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}`. ფუნქცია `dayOfYear(d, m)` ჯამავს `m - 1` თვეს და ამატებს `d`-ს. პასუხი: `dayOfYear(d2, m2) - dayOfYear(d1, m1)`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

const int DAYS[12] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

int dayOfYear(int d, int m) {
    int total = d;
    for (int i = 0; i < m - 1; i++) {
        total += DAYS[i];
    }
    return total;
}

int main() {
    int d1, m1, d2, m2;
    cin >> d1 >> m1 >> d2 >> m2;
    cout << dayOfYear(d2, m2) - dayOfYear(d1, m1) << endl;
    return 0;
}
```

ორი თარიღის შედარება ერთი კონვერტაციის ფუნქციით ბევრად უფრო მარტივია, ვიდრე თვეებისა და დღეების ცალ-ცალკე განხილვა. `const` მასივი გლობალურია, ამიტომ ფუნქციაც ხედავს და `main`-იც. იგივე სქემა გამოგადგებათ ნებისმიერი „გადაიყვანე ერთ ერთეულში“ ამოცანისთვის.
