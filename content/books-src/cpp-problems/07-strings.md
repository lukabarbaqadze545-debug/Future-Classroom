# თავი 7. სტრიქონები
weeks: 5

სტრიქონი (`string`) სიმბოლოების მიმდევრობაა და მასივივით მუშაობს: `s[i]` იძლევა i-ურ სიმბოლოს, `s.size()` — სიგრძეს. ამ თავში ვივარჯიშებთ სიმბოლოების გადარჩევასა და დათვლაში, ტექსტის წაკითხვაში სიტყვებად და სტრიქონებად (`cin >> s` და `getline`), სიმბოლოებთან არითმეტიკაში (`'a' + 1`) და სტრიქონის აგებაში.

წინაპირობა: ციკლები და `vector`. შეყვანისას ორი სხვადასხვა წესია: `cin >> s` კითხულობს **ერთ სიტყვას** (ინტერვალამდე), ხოლო `getline(cin, s)` კითხულობს **მთელ ხაზს**, ინტერვალების ჩათვლით. ამოცანის შეყვანაში დააკვირდით, რომელია საჭირო.

ყველა ტექსტი ლათინურ ასოებზე და ციფრებზე დაფუძნებულია (ASCII).

## სიგრძე, პირველი და ბოლო სიმბოლო
level: 1
tags: string, size, ინდექსი

შეყვანილია ერთი სიტყვა. გამოიტანეთ მისი სიგრძე, პირველი სიმბოლო და ბოლო სიმბოლო.

### შეყვანა

ერთი სიტყვა, რომელიც არ შეიცავს ინტერვალებს.

### გამოტანა

სამი მნიშვნელობა ერთ ხაზზე: სიგრძე, პირველი სიმბოლო, ბოლო სიმბოლო.

### შეზღუდვები

სიტყვის სიგრძე 1-დან 100-მდეა.

### მაგალითი

```in
hello
```

```out
5 h o
```

### მაგალითი

```in
a
```

```out
1 a a
```

### მინიშნებები

1. სტრიქონს ისეთივე ინდექსი აქვს, როგორც მასივს.
2. პირველი სიმბოლო: `s[0]`. სიგრძე: `s.size()`.
3. ბოლო სიმბოლოს ინდექსი `s.size() - 1`-ია. თუ სიტყვა ერთსიმბოლოიანია, პირველი და ბოლო ერთი და იგივეა.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    cout << s.size() << " " << s[0] << " " << s[s.size() - 1] << endl;
    return 0;
}
```

`s.size()` ან `s.length()` იგივეს აკეთებს. ამ მნიშვნელობას ბიბლიოთეკა `size_t` ტიპით აბრუნებს (უნიშნო რიცხვი): ამიტომ `s.size() - 1` ცარიელ სტრიქონზე ძალიან დიდ რიცხვს მოგვცემდა. აქ სიტყვა არაცარიელია, ამიტომ საფრთხე არ არის.

## ხმოვნები ტექსტში

### მინიშნებები

1. ტექსტში ინტერვალებია: რომელი წაკითხვა გამოდგება?
2. `getline(cin, s)` კითხულობს მთელ ხაზს.
3. გაიარეთ სიმბოლოები და შეამოწმეთ, არის თუ არა ის ხმოვანი. დიდი ასოები პატარად გადაიყვანეთ `tolower`-ით, რომ ორივე შემთხვევა ერთიანად დაამუშავოთ.

### ამოხსნა

```cpp
#include <cctype>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);
    int count = 0;
    for (char c : s) {
        char lower = tolower(c);
        if (lower == 'a' || lower == 'e' || lower == 'i' || lower == 'o' || lower == 'u') {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

`cin >> s` ტექსტს პირველ ინტერვალზე გაჩერდებოდა: მხოლოდ პირველ სიტყვას მივიღებდით. `getline` იკითხავს მთელ ხაზს. ციკლი `for (char c : s)` სტრიქონის თითოეულ სიმბოლოს ერთმანეთის მიყოლებით იღებს.

### სტრესი

## ციფრების ჯამი ტექსტში
level: 2
tags: string, სიმბოლოები, ციფრები

ტექსტი შეიცავს ასოებსა და ციფრებს. იპოვეთ ყველა ციფრის ჯამი (თითოეული ციფრი ცალკე ითვლება: ტექსტში „22“ ორი ციფრია, ჯამი 4).

### მინიშნებები

1. სიმბოლო `'7'` და რიცხვი 7 სხვადასხვაა. როგორ გადააქცევთ პირველს მეორედ?
2. ციფრების კოდები ზედიზედ მიდის: `'7' - '0'` არის 7.
3. გაიარეთ სიმბოლოები. თუ სიმბოლო ციფრია (`c >= '0' && c <= '9'` ან `isdigit(c)`), დაუმატეთ `c - '0'`.

### ამოხსნა

```cpp
#include <cctype>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int sum = 0;
    for (char c : s) {
        if (isdigit(c)) {
            sum += c - '0';
        }
    }
    cout << sum << endl;
    return 0;
}
```

სიმბოლოები კომპიუტერში რიცხვებია (ASCII კოდები), ციფრები კი ზედიზედ დგას: `'0'`, `'1'`, …, `'9'`. ამიტომ `c - '0'` გვაძლევს ციფრის მნიშვნელობას. იგივე იდეით `'a' + 1` არის `'b'`.

## დიდი და პატარა ასოები
level: 2
tags: string, getline, სიმბოლოები, isupper

გადააბრუნეთ ტექსტში ასოების რეგისტრი: დიდი ასო გახდეს პატარა, პატარა — დიდი. სხვა სიმბოლოები (ციფრები, ინტერვალები, ნიშნები) უცვლელი დარჩეს.

### შეყვანა

ერთი ხაზი ტექსტი.

### გამოტანა

გარდაქმნილი ტექსტი.

### შეზღუდვები

ხაზის სიგრძე 1-დან 1000-მდეა.

### მაგალითი

```in
Hello, World 123!
```

```out
hELLO, wORLD 123!
```

### შემოწმება

```in
abcXYZ
```

```out
ABCxyz
```

### მინიშნებები

1. თითოეული სიმბოლო სამგვარია: დიდი ასო, პატარა ასო ან სხვა.
2. ბიბლიოთეკა `<cctype>` იძლევა `isupper`, `islower`, `toupper`, `tolower` ფუნქციებს.
3. გაიარეთ სიმბოლოები მითითებით (`for (char &c : s)`) და თითოეული შეცვალეთ საჭიროებისას.

### ამოხსნა

```cpp
#include <cctype>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);
    for (char &c : s) {
        if (isupper(c)) {
            c = tolower(c);
        } else if (islower(c)) {
            c = toupper(c);
        }
    }
    cout << s << endl;
    return 0;
}
```

`char &c` ნიშნავს, რომ `c` თავად სტრიქონის სიმბოლოა და არა მისი ასლი, ამიტომ `c`-ს შეცვლა `s`-ს ცვლის. `&` გარეშე მხოლოდ ასლი შეიცვლებოდა და გამოტანაში არაფერი გამოსწორდებოდა.

### მინიშნებები

2. `cin >> word` ავტომატურად გამოტოვებს ინტერვალებს და იკითხავს ერთ სიტყვას.
3. წაიკითხეთ სიტყვები ციკლით, სანამ წაკითხვა წარმატებულია: `while (cin >> word) count++;`.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string word;
    int count = 0;
    while (cin >> word) {
        count++;
    }
    cout << count << endl;
    return 0;
}
```

ოპერატორი `>>` ინტერვალებს და ხაზის გადატანებს თვითონ გამოტოვებს, ამიტომ ხაზის თავში, ბოლოს და შუაში ზედმეტ ინტერვალებს ყურადღებას არ ვაქცევთ. წაკითხვის წარმატებას `while (cin >> word)` ამოწმებს: ფაილის ბოლოს ის მცდარი ხდება.

## ყველაზე გრძელი სიტყვა
level: 2
tags: string, ციკლი, მაქსიმუმი

მოცემულია `n` სიტყვა. იპოვეთ ყველაზე გრძელი. თუ ასეთი რამდენიმეა, გამოიტანეთ პირველი მათგან.

### შეყვანა

პირველ ხაზზე `n`. შემდეგ `n` სიტყვა, ინტერვალით ან ხაზის გადატანით გამოყოფილი.

### შეზღუდვები


```out

```

```in

```

```out

```

### შემოწმება

```in

```

```out

```

### მინიშნებები

1. ეს არის „უდიდესის პოვნა“ ცნობილი სქემა, ოღონდ ზომა სიგრძეა.
2. შეინახეთ ჯერჯერობით საუკეთესო სიტყვა და შეადარეთ სიგრძეები.
3. ახალი სიტყვა საუკეთესოს ანაცვლებს მხოლოდ მაშინ, როცა მისი სიგრძე **მკაცრად მეტია**: ასე პირველი რჩება.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    string best;
    for (int i = 0; i < n; i++) {
        string w;
        cin >> w;
        if (i == 0 || w.size() > best.size()) {
            best = w;
        }
    }
    cout << best << endl;
    return 0;
}
```

პირველი სიტყვა ყოველთვის ხდება საწყისი „საუკეთესო“, ხოლო დანარჩენები მას მხოლოდ მკაცრად უფრო გრძელი სიტყვით ცვლიან. ეს იგივე მუშაობა, რაც მინიმუმისა და მაქსიმუმის პოვნა მასივში.

3. `i` მარცხნიდან, `j = n - 1 - i` მარჯვნიდან. საკმარისია `i < n / 2`-მდე. თუ ერთი წყვილი არ ემთხვევა, პასუხი `NO`-ა.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();
    bool palindrome = true;
    for (int i = 0; i < n / 2; i++) {
        if (s[i] != s[n - 1 - i]) {
            palindrome = false;
        }
    }
    cout << (palindrome ? "YES" : "NO") << endl;
    return 0;
}
```

ციკლი მხოლოდ ნახევრამდე გადის, რადგან მეორე ნახევარი პირველის წყვილებია. შუა სიმბოლო (კენტი სიგრძის დროს) თავისთავს ემთხვევა და შემოწმება არ სჭირდება. `int n = s.size()` გვარიდებს `size_t`-ის უნიშნო გამოთვლებს.

2. 26 ასოს თვალყური მრიცხველების მასივით შეიძლება: ასო `'a'` უჯრა 0-ია, `'b'` უჯრა 1 და ა. შ.
3. პირველი სიტყვისთვის `count[c - 'a']++`, მეორესთვის `count[c - 'a']--`. თუ ბოლოს ყველა უჯრა ნულია, სიტყვები ანაგრამებია.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;
    int count[26] = {0};
    for (char c : a) {
        count[c - 'a']++;
    }
    for (char c : b) {
        count[c - 'a']--;
    }
    bool anagram = true;
    for (int i = 0; i < 26; i++) {
        if (count[i] != 0) {
            anagram = false;
        }
    }
    cout << (anagram ? "YES" : "NO") << endl;
    return 0;
}
```

სხვადასხვა სიგრძის სიტყვებზე ჯამი ნულისგან განსხვავდება, ამიტომ სიგრძის ცალკე შემოწმება არ გვჭირდება. მეთოდი სწრაფია: ორ გავლაზე `O(n)`, ხოლო დახარისხება `O(n log n)` იქნებოდა. გამოთვლა `c - 'a'` ასოს რიგით ნომერს (0..25) გვაძლევს.

2. გაიარეთ სიმბოლოები მიყოლებით; გახსოვდეთ მიმდინარე ჯგუფის სიმბოლო და მისი სიგრძე.
3. თუ `s[i] == s[i - 1]`, გაზარდეთ სიგრძე. თუ არა, ჩაწერეთ წინა ჯგუფი შედეგში და დაიწყეთ ახალი. ბოლო ჯგუფი ციკლის შემდეგ ჩაწერეთ.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    string result;
    int run = 1;
    for (size_t i = 1; i <= s.size(); i++) {
        if (i < s.size() && s[i] == s[i - 1]) {
            run++;
        } else {
            result += s[i - 1];
            result += to_string(run);
            run = 1;
        }
    }
    cout << result << endl;
    return 0;
}
```

ციკლი `i <= s.size()`-მდე მიდის: უკანასკნელ საფეხურზე `i == s.size()`, ამიტომ პირობა `i < s.size()` მცდარია და ბოლო ჯგუფიც ჩაიწერება. ასე ბოლო ჯგუფისთვის ციკლის შემდეგ ცალკე კოდი აღარ გვჭირდება. ჯგუფების მიყოლებით დამუშავება კიდევ ბევრჯერ გამოგადგებათ.

2. დაწყების ყოველი შესაძლო პოზიციისთვის შეადარეთ `p` ტექსტის შესაბამის ნაწილს.
3. `i` იცვლება 0-დან `t.size() - p.size()`-მდე (თუ `p` უფრო გრძელია, ციკლი არ სრულდება). შეადარეთ `t.substr(i, p.size()) == p`.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string t, p;
    cin >> t >> p;
    int count = 0;
    for (int i = 0; i + (int)p.size() <= (int)t.size(); i++) {
        if (t.substr(i, p.size()) == p) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

პირობა `i + p.size() <= t.size()` გვიცავს ტექსტის საზღვრებიდან გასვლისგან. ეს მიდგომა ყოველი პოზიციისთვის ნიმუშის სიგრძეზე შედარებას აკეთებს და ამიტომ ნელია უფრო დიდ ტექსტებზე (10⁶ სიმბოლო), თუმცა 1000-ზე კომფორტულად ეტევა. სწრაფი ალგორითმები (KMP, Z-ფუნქცია) უფრო მოწინავე თემებია.

## კეისარის შიფრი
level: 3
tags: string, getline, სიმბოლოები, %

კეისარის შიფრი ყოველ ლათინურ ასოს ანაცვლებს ასოთი, რომელიც ანბანში `k` პოზიციით შემდეგ დგას (`z`-ის შემდეგ ისევ `a` მოდის). დიდი და პატარა ასოები თავისთავად რჩება: `Z` გადადის `A`-ში. სხვა სიმბოლოები (ინტერვალები, ციფრები, ნიშნები) უცვლელია. დაშიფრეთ ტექსტი.

### შეყვანა

### მინიშნებები

1. ანბანში 26 ასოა და წანაცვლება ციკლურია. `k = 26` არაფერს ცვლის.
2. პირველად შეამცირეთ `k % 26`. ასოს ახალი ადგილი: `(ადგილი + k) % 26`.
3. პატარა ასო `c`-სთვის: `(c - 'a' + k) % 26 + 'a'`. დიდისთვის: `'A'`. ყურადღება: `cin >> k`-ის შემდეგ ხაზის გადატანა ბუფერში რჩება; ტექსტის წაკითხვამდე გამოიყენეთ `cin.ignore()`.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int k;
    cin >> k;
    cin.ignore();
    string s;
    getline(cin, s);
    k %= 26;
    for (char &c : s) {
        if (c >= 'a' && c <= 'z') {
            c = (c - 'a' + k) % 26 + 'a';
        } else if (c >= 'A' && c <= 'Z') {
            c = (c - 'A' + k) % 26 + 'A';
        }
    }
    cout << s << endl;
    return 0;
}
```

`cin >> k` რიცხვს კითხულობს, მაგრამ ხაზის გადატანას ბუფერში ტოვებს. თუ მაშინვე `getline` გამოიძახეთ, ის ცარიელ ხაზს წაიკითხავს. `cin.ignore()` ამ ერთ სიმბოლოს გამოტოვებს. ეს ერთ-ერთი ყველაზე ხშირი შეცდომაა `cin`-ისა და `getline`-ის შერევისას.

### სტრესი

```brute
#include <iostream>
#include <string>
using namespace std;

int main() {
    int k;
    cin >> k;
    cin.ignore();
    string s;
    getline(cin, s);
    for (int step = 0; step < k; step++) {
        for (char &c : s) {
            if (c == 'z') c = 'a';
            else if (c == 'Z') c = 'A';
            else if ((c >= 'a' && c < 'z') || (c >= 'A' && c < 'Z')) c++;
        }
    }
    cout << s << endl;
    return 0;
}
```

## დიდი რიცხვების შეკრება

tags: string, გადატანა, დიდი რიცხვები

### მინიშნებები

1. როგორ ვკრებთ რიცხვებს ფურცელზე? ბოლო ციფრებიდან, გადატანით.
2. შეატრიალეთ ორივე სტრიქონი, რომ უმცირესი თანრიგი პირველი იყოს, ან გაივლეთ ბოლოდან.
3. იარეთ ციფრებზე და ჩაიწერეთ `carry`. თითოეულ თანრიგზე `sum = a_digit + b_digit + carry`; ჩაწერეთ `sum % 10`, `carry = sum / 10`. ბოლოს დარჩენილი `carry` დაამატეთ. პასუხი შეატრიალეთ.

### ამოხსნა

```cpp
#include <algorithm>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    cin >> a >> b;
    int i = (int)a.size() - 1;
    int j = (int)b.size() - 1;
    int carry = 0;
    string result;
    while (i >= 0 || j >= 0 || carry > 0) {
        int sum = carry;
        if (i >= 0) {
            sum += a[i--] - '0';
        }
        if (j >= 0) {
            sum += b[j--] - '0';
        }
        result += char('0' + sum % 10);
        carry = sum / 10;
    }
    reverse(result.begin(), result.end());
    cout << result << endl;
    return 0;
}
```

ეს არის სვეტებში შეკრება კოდით. ციკლი გრძელდება, სანამ ერთ-ერთ რიცხვში ციფრები დარჩა ან გადატანაა (მაგალითად, `999 + 1`-ზე ბოლოს გადატანა ახალ ციფრს ქმნის). ნული შეყვანისას `0 + 0` ციკლში ერთხელ შეგვიყვანს და `0` დაიწერება.
