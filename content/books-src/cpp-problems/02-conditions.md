### მინიშნებები

1. რა ნაშთი რჩება ლუწი რიცხვის 2-ზე გაყოფისას?
2. გამოიყენეთ `%`. უარყოფით რიცხვებზე კი ფრთხილად: რას გამოიტანს C++ ამ გამოსახულებაზე `-3 % 2`?
3. `-3 % 2` არის `-1` და არა `1`, ამიტომ კენტობა `n % 2 == 1` პირობით არასწორად შემოწმდება. შეამოწმეთ ლუწობა: `n % 2 == 0`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "even" << endl;
    } else {
        cout << "odd" << endl;
    }
    return 0;
}
```

C++-ში ნაშთის ნიშანი პირველი რიცხვის ნიშანს მისდევს: `-3 % 2` არის `-1`. ამიტომ უფრო საიმედოა შევამოწმოთ, ნულის ტოლია თუ არა ნაშთი, ვიდრე 1-ის ტოლია თუ არა.

### მინიშნებები

1. შეადარეთ ორი რიცხვი ერთმანეთს.
2. პირობა `a > b` სამართლიანია მხოლოდ ერთ შემთხვევაში. რა გამოიტანება დანარჩენში?
3. თუ `a > b`, გამოიტანეთ `a`; წინააღმდეგ შემთხვევაში `b`. ტოლობის შემთხვევა ორივე ვარიანტში ავტომატურად სწორია.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a > b) {
        cout << a << endl;
    } else {
        cout << b << endl;
    }
    return 0;
}
```

ტოლობის შემთხვევაში `a > b` მცდარია და გამოდის `b`, რომელიც `a`-ს ტოლია. ტოლობას ცალკე შემოწმება არ სჭირდება.

### მინიშნებები

1. სამი შესაძლო პასუხია. როგორ გამოიყენებთ ორ `if`-ს სამი შემთხვევის გასარჩევად?
2. ჯაჭვი `if ... else if ... else`.
3. შეამოწმეთ `n > 0`, შემდეგ `n < 0`; დარჩენილი შემთხვევა მხოლოდ ნულია.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n > 0) {
        cout << "positive" << endl;
    } else if (n < 0) {
        cout << "negative" << endl;
    } else {
        cout << "zero" << endl;
    }
    return 0;
}
```

`else if` ჯაჭვი ზემოდან ქვემოთ მიდის და პირველივე ჭეშმარიტ პირობას ასრულებს. `else` იჭერს ყველა დანარჩენს, ამ შემთხვევაში ნულს.

### მინიშნებები

1. დახარისხების ნაცვლად იფიქრეთ: ვის ეძახით შუას? ის ერთზე დიდი და მეორეზე პატარაა (ან ტოლი).
2. შეგიძლიათ შეადაროთ წყვილები და გადააბრუნოთ ისე, რომ `a ≤ b ≤ c` გახდეს. ან გამოიყენეთ ჯამი მინუს უდიდესი მინუს უმცირესი.
3. წყვილების გაცვლის გზა: თუ `a > b`, გაცვალეთ; თუ `b > c`, გაცვალეთ; თუ `a > b`, ისევ გაცვალეთ. ბოლოს `b` არის მედიანა. თუ ჯამს ცდით, `long long` გამოიყენეთ.

### ამოხსნა

```cpp
#include <iostream>
#include <utility>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a > b) swap(a, b);
    if (b > c) swap(b, c);
    if (a > b) swap(a, b);
    cout << b << endl;
    return 0;
}
```

სამი შედარება-გაცვლა ალაგებს სამ რიცხვს: პირველი ორი უდიდესს `c`-ში გადაიტანს, მესამე კი `a`-სა და `b`-ს ალაგებს. ამოხსნა `a + b + c - max - min` ფორმულითაც შეიძლება, მაგრამ ჯამი 3 · 10⁹-მდე გაიზრდება და `int`-ში არ ეტევა: გადავსების შეცდომა ზუსტად ასეთ ზღვრულ ტესტზე გამოჩნდება.

### მინიშნებები

1. იფიქრეთ: რა დაკავშირებაა სამკუთხედის გვერდებს შორის? ორი გვერდი ერთად უნდა ფარავდეს მესამეს.
2. სამკუთხედის უტოლობა: ნებისმიერი ორი გვერდის ჯამი მესამეზე მეტი უნდა იყოს. თანაბარი ჯამი საკმარისი არ არის.
3. შეამოწმეთ სამივე უტოლობა `&&`-ით: `a + b > c`, `a + c > b`, `b + c > a`. ჯამი 2 · 10⁹-ს არ აღემატება და `int`-ში ეტევა.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a + b > c && a + c > b && b + c > a) {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
    return 0;
}
```

სამივე უტოლობის შემოწმება აუცილებელია, რადგან წინასწარ არ ვიცით, რომელია უდიდესი გვერდი (სინამდვილეში საკმარისია უდიდესის შემოწმება, მაგრამ მისი პოვნა დამატებით ნაბიჯს ითხოვს). უტოლობა მკაცრია, ამიტომ დეგენერაციული შემთხვევა (`1 2 3`) მცდარად ითვლება.

## სამკუთხედის სახეობა
level: 2
tags: if, სამკუთხედი, შედარება

გვერდები უკვე ქმნის სამკუთხედს. გამოიტანეთ მისი სახეობა: `equilateral` (ტოლგვერდა), `isosceles` (ტოლფერდა, მაგრამ არა ტოლგვერდა) ან `scalene` (არატოლგვერდა).

### მინიშნებები

1. რამდენ ტოლობას შეგვიძლია სამ რიცხვს შორის ვიპოვოთ?
2. ჯერ შეამოწმეთ ყველაზე „ძლიერი“ შემთხვევა: ყველა სამი ტოლია. მხოლოდ შემდეგ ორი ტოლი.
3. თუ `a == b && b == c`, ეს ტოლგვერდაა. თუ ტოლია ნებისმიერი წყვილი (`a == b || a == c || b == c`), ეს ტოლფერდაა. დანარჩენი შემთხვევა არატოლგვერდაა.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a == b && b == c) {
        cout << "equilateral" << endl;
    } else if (a == b || a == c || b == c) {
        cout << "isosceles" << endl;
    } else {
        cout << "scalene" << endl;
    }
    return 0;
}
```

შემოწმებათა რიგი მნიშვნელოვანია: თუ ტოლფერდობას პირველს შეამოწმებთ, ტოლგვერდა სამკუთხედიც „ტოლფერდა“ გამოვა.

```cpp
}
```

ლოგიკური ცვლადი `leap` პირობას სახელს აძლევს და პროგრამას უფრო გასაგებს ხდის. ბრჭყალებში `?:` სამწევრიანი ოპერატორია: მოკლე `if / else` გამოსატანი მნიშვნელობისთვის.

## თვის დღეები
level: 2
tags: switch, ნაკიანი წელი

შეყვანილია წელი და თვის ნომერი (1 — იანვარი, … 12 — დეკემბერი). გამოიტანეთ, რამდენი დღეა ამ თვეში ამ წელს.

### შეყვანა

ერთ ხაზზე ორი რიცხვი: წელი `y` და თვე `m`.

### გამოტანა

ერთი რიცხვი: დღეების რაოდენობა.

### შეზღუდვები

1 ≤ y ≤ 10⁹, 1 ≤ m ≤ 12. ნაკიანი წლის წესი იგივეა, რაც წინა ამოცანაში.

```out
29
```

```in
2023 2
```

```out
28
```



### მინიშნებები

1. თვეების უმეტესობას დღეები ფიქსირებული აქვს. რომელს არა?
2. `switch` კარგად ერგება: ერთი `case` რამდენიმე თვეს ერთად უნდა ფარავდეს (4, 6, 9, 11).
3. თებერვლისთვის გამოთვალეთ ნაკიანობა; დანარჩენი თვეები: 31 დღე, გარდა აპრილის, ივნისის, სექტემბრისა და ნოემბრისა, რომლებშიც 30 დღეა.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int y, m;
    cin >> y >> m;
    int days = 31;
    switch (m) {
        case 4:
        case 6:
        case 9:
        case 11:
            days = 30;
            break;
        case 2:
            days = ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0) ? 29 : 28;
            break;
    }
    cout << days << endl;
    return 0;
}
```

`case`-ები `break`-მდე „ერთად მუშაობს“: 4, 6, 9, 11 ერთსა და იმავე კოდს აღწევს. `days`-ს წინასწარ 31 ვაძლევთ, ამიტომ დარჩენილი შვიდი თვე ცალკე შემთხვევებს არ საჭიროებს. `break`-ის დავიწყება ხშირი შეცდომაა: პროგრამა შემდეგ `case`-ში „ჩაივარდება“.

## ქულა და შეფასება

### მინიშნებები

1. ზღვრები ორმხრივად ხშირი შეცდომის წყაროა. 80 რომელ ინტერვალს ეკუთვნის?
2. ჩამოწერეთ პირობები ზემოდან ქვემოთ: თუ `s ≥ 90`, მერე `s ≥ 80`, და ა. შ.
3. `else if` ჯაჭვში ქვედა ზღვარი ზედაზე უკვე არის გამორიცხული, ამიტომ ყოველ ეტაპზე მხოლოდ ქვედა ზღვარი შეამოწმეთ.

```cpp
#include <iostream>

int main() {
    int s;
    cin >> s;
    if (s >= 90) {
        cout << "A" << endl;
    } else if (s >= 80) {
        cout << "B" << endl;
    } else if (s >= 70) {
        cout << "C" << endl;
    } else if (s >= 60) {
        cout << "D" << endl;
    } else {
        cout << "F" << endl;
    }
    return 0;
}
```

## კალკულატორი
level: 2
tags: switch, char, არითმეტიკა

შეყვანილია გამოსახულება `a op b`, სადაც `op` არის ერთ-ერთი სიმბოლო `+`, `-`, `*`, `/`. გამოიტანეთ მისი მნიშვნელობა. გაყოფა მთელია (წილადი ნაწილი უგულებელყოფილია: 7 / 2 = 3). თუ `b` ნულია და ოპერაცია გაყოფაა, გამოიტანეთ `ERROR`.

### შეყვანა

ერთ ხაზზე ინტერვალებით გამოყოფილი `a`, სიმბოლო `op` და `b`.

### გამოტანა

გამოთვლის შედეგი ან სიტყვა `ERROR`.

### შეზღუდვები

0 ≤ a, b ≤ 10⁴

### მაგალითი

```in
6 * 7
```

```out
42
```

### მაგალითი

```in
7 / 2
```

```out
3
```

### მაგალითი

```in
5 / 0
```

```out
ERROR
```

### შემოწმება

```in
10 - 25
```

```out
-15
```

```in
3 + 4
```

```out
7
```

### მინიშნებები

1. ოპერაციის ნიშანი ტექსტური სიმბოლოა: რომელი ტიპი ინახავს ერთ სიმბოლოს?
2. `cin >> a >> op >> b` წაიკითხავს სამივეს, ინტერვალებით გამოყოფილს. `switch` შეიძლება `char`-ზეც.
3. `switch (op)`-ში ოთხი `case`; გაყოფის შემთხვევაში ჯერ `b == 0` შეამოწმეთ.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    char op;
    cin >> a >> op >> b;
    switch (op) {
        case '+':
            cout << a + b << endl;
            break;
        case '-':
            cout << a - b << endl;
            break;
        case '*':
            cout << a * b << endl;
            break;
        case '/':
            if (b == 0) {
                cout << "ERROR" << endl;
            } else {
                cout << a / b << endl;
            }
            break;
    }
    return 0;
}
```

ერთი სიმბოლო ერთბრჭყალებშია (`'+'`), სტრიქონი კი ორბრჭყალებში (`"+"`): ეს განსხვავება მნიშვნელოვანია, `switch` მხოლოდ პირველით მუშაობს. ნულზე გაყოფა პროგრამას გააჩერებდა, ამიტომ ის წინასწარ უნდა გამოვიჭიროთ.

## წერტილი მართკუთხედთან
level: 3
tags: if, &&, გეომეტრია, ზღვრული შემთხვევები

მართკუთხედის გვერდები კოორდინატთა ღერძების პარალელურია. მოცემულია მისი ქვედა მარცხენა კუთხე `(x1, y1)` და ზედა მარჯვენა კუთხე `(x2, y2)`, ასევე წერტილი `(x, y)`. გამოიტანეთ `inside`, თუ წერტილი მართკუთხედის შიგნითაა, `border`, თუ მისი გვერდზე ან კუთხეზეა, და `outside`, თუ გარეთაა.

### შეყვანა

პირველ ხაზზე ოთხი რიცხვი: `x1 y1 x2 y2`. მეორე ხაზზე ორი რიცხვი: `x y`.

### გამოტანა

`inside`, `border` ან `outside`.

### შეზღუდვები

−10⁹ ≤ კოორდინატი ≤ 10⁹, x1 < x2, y1 < y2

### მაგალითი

```in
2 1
```

```out

```

### მაგალითი

```in
0 0 4 3
4 2
```

```out
border
```

### მაგალითი

```in
0 0 4 3
5 1
```

```out
outside
```

### შემოწმება

```in
0 0 4 3
0 0
```

```out
border
```

```in

-6 0
```

```out

```

```in
0 0 4 3
```


### მინიშნებები

1. წერტილი მართკუთხედთან მიმართებაში სამგვარია. ჯერ დაადგინეთ, როდის არის ის ნამდვილად გარეთ.
2. წერტილი გარეთაა, თუ `x` ან `y` გასცდა დიაპაზონს. თუ არ გასცდა, ის არის ან შიგნით, ან გვერდზე.
3. თუ `x` მკაცრად `x1`-სა და `x2`-ს შორისაა და `y` მკაცრად `y1`-სა და `y2`-ს შორის, ეს შიგნითაა. თუ არ არის გარეთ და არ არის შიგნით, ის გვერდზეა.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int x1, y1, x2, y2, x, y;
    cin >> x1 >> y1 >> x2 >> y2 >> x >> y;
    if (x < x1 || x > x2 || y < y1 || y > y2) {
        cout << "outside" << endl;
    } else if (x > x1 && x < x2 && y > y1 && y < y2) {
        cout << "inside" << endl;
    } else {
        cout << "border" << endl;
    }
    return 0;
}
```

სამ შემთხვევას ორი პირობა ჰყოფს: „გარეთაა“ და „მკაცრად შიგნითაა“. დარჩენილი ყველა წერტილი გვერდზეა, ამიტომ მესამე შემთხვევას საკუთარი პირობა არ სჭირდება. ტესტებში აუცილებლად შეამოწმეთ კუთხეები: ისინი ყველაზე ხშირად ცდება.
