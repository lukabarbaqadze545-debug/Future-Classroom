# თავი 10. სირთულე და სრული გადარჩევა
weeks: 7

ძირითადი შეკითხვა, რომელსაც ამოცანის წაკითხვისთანავე უნდა დასვათ: **ჩემი მეთოდი ეტევა თუ არა დროში?** კომპიუტერი ერთ წამში დაახლოებით 10⁸ მარტივ ოპერაციას ასრულებს. შეზღუდვებს წაიკითხავთ და ამით მიხვდებით, რა სირთულის ამოხსნა გამოდგება:

- `n ≤ 10`: შეიძლება `n!` გადარჩევა (ყველა გადანაცვლება).
- `n ≤ 20`: შეიძლება `2ⁿ` გადარჩევა (ყველა ქვესიმრავლე).
- `n ≤ 300`: `n³` ეტევა.
- `n ≤ 5000`: `n²` ეტევა.
- `n ≤ 10⁶`: საჭიროა `n` ან `n log n`.
- `n ≤ 10¹⁸`: საჭიროა `log n` ან ფორმულა.

სრული გადარჩევა (brute force) ნიშნავს, რომ ყველა შესაძლო ვარიანტს ვამოწმებთ. ის ხშირად უმარტივესი ამოხსნაა, დაუშვებელია დიდ შეზღუდვებზე, მაგრამ ორი მიზეზით მაინც ღირებულია: პატარა შეზღუდვებზე ის საკმარისია, და ის უკეთესი ამოხსნის შესამოწმებლად გამოდგება: წერთ ჭკვიან პროგრამას, ადარებთ გადარჩევას პატარა ტესტებზე და შეცდომებს იჭერთ.

წინაპირობა: წინა თავები. ამოცანის პირობაში ყოველთვის წაიკითხეთ შეზღუდვები სანამ ამოხსნას დაიწყებთ.

## რამდენჯერ შესრულდება
level: 2
kind: predict
tags: ვარაუდი, სირთულე, ჩადგმული ციკლები

რას დაბეჭდავს ეს პროგრამა?

```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 0;
    for (int i = 1; i <= 5; i++) {
        for (int j = i; j <= 5; j++) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

### მინიშნებები

1. ყოველ `i`-ზე რამდენჯერ სრულდება შიდა ციკლი?
2. `i = 1`-ზე `j` 1-დან 5-მდე გადის, `i = 2`-ზე 2-დან 5-მდე.

### ამოხსნა

```out
15
```

5 + 4 + 3 + 2 + 1 = 15. საერთო ფორმულა: `n · (n + 1) / 2`, ანუ დაახლოებით `n²/2`: ორმაგი ციკლი მიახლოებით კვადრატულია, `n = 10⁵`-ზე ეს 5 მილიარდია და ძალიან ნელი.

## ყველა ორობითი სტრიქონი

### მინიშნებები

1. ორობითი სტრიქონი ორობითი რიცხვია. რომელ რიცხვებს გაივლით 0-დან `2ⁿ − 1`-მდე?
2. `1 << n` არის `2ⁿ`. ციკლი `mask = 0`-დან `(1 << n) - 1`-მდე გადის ყველა ვარიანტს ზრდადობით.
3. `mask`-ის ბიტები გამოიტანეთ უფროსიდან უმცროსისკენ: `(mask >> bit) & 1` იძლევა `bit`-ურ ბიტს.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int mask = 0; mask < (1 << n); mask++) {
        for (int bit = n - 1; bit >= 0; bit--) {
            cout << ((mask >> bit) & 1);
        }
        cout << "\n";
    }
    return 0;
}
```

რიცხვი `mask` ერთდროულად ორ როლს ასრულებს: ის რიცხვია და ის `n` ბიტიანი „არჩევანია“. ეს ხრიკი (ბიტმასკა) შემდეგ ამოცანებში ქვესიმრავლეების გადასარჩევადაც გამოგადგებათ: ბიტი 1-ია, თუ ელემენტი არჩეულია.

## სამი რიცხვის ჯამი ნულია
level: 2
tags: სამმაგი ციკლი, სრული გადარჩევა, სირთულე

მოცემულია `n` რიცხვი. დაითვალეთ, რამდენი სხვადასხვა სამეული (`i < j < k`, პოზიციები) აქვს ჯამი ნული.

### შეყვანა

პირველ ხაზზე `n`. მეორე ხაზზე `n` მთელი რიცხვი.

### გამოტანა

ერთი რიცხვი: სამეულების რაოდენობა.

### შეზღუდვები

3 ≤ n ≤ 300, |რიცხვი| ≤ 10⁹

### მაგალითი

```in
-1 0 1 2 -1
```

```out

```

### განმარტება

სამეულებია პოზიციებით (1, 2, 3), (1, 4, 5) და (2, 3, 5): მნიშვნელობებია (−1, 0, 1), (−1, 2, −1) და (0, 1, −1).

### შემოწმება

```in

0 0 0
```

```out
1
```

```in

1000000000 1000000000 -1000000000
```


### მინიშნებები

1. სამეული სამი სხვადასხვა პოზიციაა. როგორ აღწერთ ყველა ასეთ სამეულს ციკლებით?
2. სამი ჩადგმული ციკლი: `i`, `j = i + 1`-დან, `k = j + 1`-დან.
3. `n = 300`-ზე სამეულები დაახლოებით 4,5 მილიონია, ამიტომ პირდაპირი გადარჩევა კომფორტულია. ჯამს `long long`-ში აკრიფეთ: სამი რიცხვის ჯამი 3 · 10⁹-მდეა.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int count = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            for (int k = j + 1; k < n; k++) {
                if (a[i] + a[j] + a[k] == 0) {
                    count++;
                }
            }
        }
    }
    cout << count << endl;
    return 0;
}
```

სამ ჩადგმულ ციკლს `O(n³)` დრო სჭირდება: `n = 300`-ზე დაახლოებით 4,5 · 10⁶, `n = 3000`-ზე კი 4,5 · 10⁹, ანუ ძალიან ნელია. ეს არის ძირითადი გაკვეთილი: ყოველთვის შეადარეთ ოპერაციათა რაოდენობა შეზღუდვას. უფრო სწრაფი მეთოდი (დახარისხება და ორი მაჩვენებელი) მე-11 თავშია.

## წყვილები, რომელთა ჯამი იყოფა k-ზე
level: 2
tags: ჩადგმული ციკლები, სრული გადარჩევა, %

დაითვალეთ, რამდენი წყვილი `(i, j)` პოზიციაა (`i < j`), რომლებისთვისაც `a[i] + a[j]` იყოფა `k`-ზე.

### შეყვანა

პირველ ხაზზე `n` და `k`. მეორე ხაზზე `n` მთელი რიცხვი.

### გამოტანა

ერთი რიცხვი: წყვილების რაოდენობა.

### შეზღუდვები

### მაგალითი

```in

1 2 3 4 5
```

```out

```

### განმარტება

წყვილების ჯამებია 3 (1 + 2), 6 (1 + 5), 6 (2 + 4) და 9 (4 + 5).

### შემოწმება

```in
1 1
```

```out

```



### მინიშნებები

1. როცა `n ≤ 2000`, ყველა წყვილის შემოწმება 2 მილიონ ოპერაციას ითხოვს. ეს მცირეა.
2. ორი ჩადგმული ციკლი, `j` იწყება `i + 1`-დან.
3. შეამოწმეთ `(a[i] + a[j]) % k == 0`. ჯამი 2 · 10⁹-ს აღწევს: გამოიყენეთ `long long`.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    long long k;
    cin >> n >> k;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int count = 0;
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if ((a[i] + a[j]) % k == 0) {
                count++;
            }
        }
    }
    cout << count << endl;
    return 0;
}
```

ეს მეთოდი სწორია და `n = 2000`-ზე სწრაფი. თუ `n = 10⁵` იქნებოდა, ორი მილიარდი წყვილი ძალიან ნელი გამოვიდოდა: მაშინ გაითვალისწინებდით, რომ ჯამი იყოფა `k`-ზე მაშინ, როცა ნაშთები `r` და `k − r` ერთმანეთს ავსებს, და მოგიწევდათ ნაშთების დათვლა. ამიტომ ჯერ ყოველთვის შეზღუდვები წაიკითხეთ.

### სტრესი

```brute
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    long long k;
    cin >> n >> k;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    int ordered = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (i != j && (a[i] + a[j]) % k == 0) ordered++;
    cout << ordered / 2 << endl;
    return 0;
}
```

## პითაგორას სამეულები
level: 3
tags: სრული გადარჩევა, ჩადგმული ციკლები, ოპტიმიზაცია

დაითვალეთ, რამდენი სამეულია `(a, b, c)`, სადაც `1 ≤ a ≤ b ≤ c ≤ n` და `a² + b² = c²`.

### შეყვანა

ერთი მთელი რიცხვი `n`.

### გამოტანა

ერთი რიცხვი: სამეულების რაოდენობა.

### შეზღუდვები

### მაგალითი

```in

```

```out

```

### განმარტება

ერთადერთი სამეულია (3, 4, 5).

### მაგალითი

```in

```

```out

```

### შემოწმება

```in

```


### მინიშნებები

1. სამი ჩადგმული ციკლი მუშაობს, მაგრამ `n = 3000`-ზე 2,7 · 10¹⁰ ოპერაციაა. ჩადგმული ციკლებიდან ერთი ზედმეტია?
2. როცა `a` და `b` ცნობილია, `c` ცალსახად განისაზღვრება: `c² = a² + b²`.
3. ორი ციკლი `a`-ზე და `b ≥ a`-ზე; დაითვალეთ `s = a² + b²` და იპოვეთ მთელი `c` ისეთი, რომ `c² = s`. თუ `c ≤ n`, დაამატეთ. მთელი ფესვი იპოვეთ ისე, როგორც „სრული კვადრატები“ ამოცანაში.

### ამოხსნა

```cpp
#include <cmath>
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    for (long long a = 1; a <= n; a++) {
        for (long long b = a; b <= n; b++) {
            long long s = a * a + b * b;
            long long c = (long long)sqrt((double)s);
            while (c * c < s) c++;
            while (c * c > s) c--;
            if (c * c == s && c <= n) {
                count++;
            }
        }
    }
    cout << count << endl;
    return 0;
}
```

სამ ციკლს ორი ციკლი ცვლის: `c` აღარ გვჭირდება, რადგან მას ფორმულით ვპოულობთ. ოპერაციები 2,7 · 10¹⁰-დან დაახლოებით 4,5 · 10⁶-მდე შემცირდა. ეს არის გადარჩევის დაჩქარების ტიპური ხერხი: ყოველთვის ვეძებთ ცვლადს, რომელიც სხვებით ცალსახად განისაზღვრება და ციკლს აღარ საჭიროებს.

### სტრესი

```brute
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    for (int a = 1; a <= n; a++)

            for (int c = b; c <= n; c++)
                if (a * a + b * b == c * c) count++;
    cout << count << endl;
    return 0;
}
```

მოცემულია `n` დადებითი რიცხვი. დაითვალეთ, რამდენი ქვესიმრავლე (რიცხვების არჩევის სხვადასხვა ვარიანტი პოზიციების მიხედვით) აქვს ჯამი ზუსტად `S`. ცარიელი ქვესიმრავლე არ ითვლება.

### შეყვანა

პირველ ხაზზე `n` და `S`. მეორე ხაზზე `n` მთელი რიცხვი.

### მინიშნებები

1. `n ≤ 20` ნიშნავს, რომ `2ⁿ ≈ 10⁶` ქვესიმრავლე ჯერ კიდევ ეტევა.
2. რიცხვი `mask` 0-დან `2ⁿ − 1`-მდე ქვესიმრავლეს გამოხატავს: `i`-ური ბიტი 1-ია, თუ `a[i]` არჩეულია.
3. თითოეული `mask`-ისთვის დაითვალეთ ჯამი ბიტებზე გავლით. ცარიელი ქვესიმრავლე (`mask = 0`) ჯამით 0-ს იძლევა, ხოლო `S ≥ 1`, ამიტომ ის თავისთავად არ დაითვლება.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    long long S;
    cin >> n >> S;
    vector<long long> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int count = 0;
    for (int mask = 1; mask < (1 << n); mask++) {
        long long sum = 0;
        for (int i = 0; i < n; i++) {
            if (mask & (1 << i)) {
                sum += a[i];
            }
        }
        if (sum == S) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

`mask & (1 << i)` ამოწმებს, არის თუ არა `i`-ური ბიტი ჩართული. ერთნაირი მნიშვნელობები სხვადასხვა პოზიციაზე სხვადასხვა ქვესიმრავლეს ქმნის (მეორე მაგალითი). სირთულე `O(2ⁿ · n)`: `n = 20`-ზე დაახლოებით 2 · 10⁷ ოპერაცია, ანუ წამზე ბევრად ნაკლები.

### სტრესი

```brute
#include <iostream>
#include <vector>
using namespace std;

int n;
long long S;
vector<long long> a;

int go(int i, long long left) {
    if (i == n) return left == 0 ? 1 : 0;
    return go(i + 1, left) + go(i + 1, left - a[i]);
}

int main() {
    cin >> n >> S;
    a.resize(n);
    for (auto &x : a) cin >> x;
    cout << go(0, S) << endl;
    return 0;
}
```

## ზურგჩანთა გადარჩევით
level: 3
tags: ბიტმასკა, სრული გადარჩევა, ზურგჩანთა

ტურისტს სურს ზურგჩანთაში ნივთები ჩაალაგოს. ყოველ ნივთს აქვს წონა და ფასეულობა; ზურგჩანთა `W` წონამდე იტევს. აირჩიეთ ნივთების ისეთი ნაკრები, რომლის ჯამური წონა `W`-ს არ აღემატება და ჯამური ფასეულობა უდიდესია. თითოეული ნივთი ერთხელ შეიძლება აიღოთ.

### შეყვანა

პირველ ხაზზე `n` და `W`. შემდეგ `n` ხაზზე ორი რიცხვი: ნივთის წონა და ფასეულობა.

### გამოტანა

### შეზღუდვები

### მინიშნებები

1. ყოველი ნივთი ან ავიღოთ, ან არა: ეს ბიტმასკის ტიპური ამოცანაა.
2. ყველა `2ⁿ` ქვესიმრავლისთვის დათვალეთ ჯამური წონა და ფასეულობა.
3. თუ ჯამური წონა `W`-ს არ აღემატება, შეადარეთ ფასეულობა ჯერჯერობით საუკეთესოს. ცარიელი ქვესიმრავლეც დასაშვებია (ფასეულობა 0).

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    long long W;
    cin >> n >> W;
    vector<long long> w(n), v(n);
    for (int i = 0; i < n; i++) {
        cin >> w[i] >> v[i];
    }
    long long best = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        long long weight = 0, value = 0;
        for (int i = 0; i < n; i++) {
            if (mask & (1 << i)) {
                weight += w[i];
                value += v[i];
            }
        }
        if (weight <= W && value > best) {
            best = value;
        }
    }
    cout << best << endl;
    return 0;
}
```

ეს ზუსტად ის მეთოდია, რომელიც `n ≤ 20`-ზე მუშაობს; თუ `n = 100` იქნებოდა, `2¹⁰⁰` ვარიანტი ვერასოდეს დასრულდებოდა. ამავე ამოცანის უფრო ეფექტურ ამოხსნას (დინამიურ პროგრამირებას) მე-14 თავში ისევ შეხვდებით: შეადარეთ ორივე და დაინახავთ, როგორ ზრდის უკეთესი იდეა დასაშვებ `n`-ს.

### სტრესი

```brute
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int n;
long long W;
vector<long long> w, v;

long long go(int i, long long left) {
    if (i == n) return 0;
    long long best = go(i + 1, left);
    if (w[i] <= left) best = max(best, v[i] + go(i + 1, left - w[i]));
    return best;
}

int main() {
    cin >> n >> W;
    w.resize(n);
    v.resize(n);
    for (int i = 0; i < n; i++) cin >> w[i] >> v[i];
    cout << go(0, W) << endl;
    return 0;
}
```

## გადანაცვლებები უძრავი წერტილის გარეშე
level: 3
tags: გადანაცვლებები, next_permutation, სრული გადარჩევა

გადანაცვლება რიცხვების 1-დან `n`-მდე რიგი. ამბობენ, რომ გადანაცვლებას უძრავი წერტილი აქვს, თუ რომელიმე `i`-სთვის `i`-ურ პოზიციაზე სწორედ რიცხვი `i` დგას. დაითვალეთ, რამდენი გადანაცვლებაა უძრავი წერტილის გარეშე.

### გამოტანა

### მინიშნებები

1. `n ≤ 9` ნიშნავს, რომ `9! = 362 880` გადანაცვლება ჯერ კიდევ ეტევა.
2. C++ აქვს `next_permutation`: ის მიმდევრობას შემდეგ ლექსიკოგრაფიულ გადანაცვლებაში გადააქცევს (და აბრუნებს `false`-ს, როცა ბოლო ამოიწურა).
3. შექმენით `p = {1, 2, …, n}`; `do { შეამოწმე } while (next_permutation(p.begin(), p.end()));`. შემოწმება: არსებობს თუ არა `i`, რომელზეც `p[i] == i + 1`.

### ამოხსნა

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> p(n);
    iota(p.begin(), p.end(), 1);
    int count = 0;
    do {
        bool hasFixedPoint = false;
        for (int i = 0; i < n; i++) {
            if (p[i] == i + 1) {
                hasFixedPoint = true;
            }
        }
        if (!hasFixedPoint) {
            count++;
        }
    } while (next_permutation(p.begin(), p.end()));
    cout << count << endl;
    return 0;
}
```

`iota` ავსებს მასივს მიმდევრობით 1, 2, 3, … `next_permutation` ყველა გადანაცვლებას გაიძლევს ერთხელ, ზრდადი ლექსიკოგრაფიული რიგით, ამიტომ დაწყება აუცილებლად დახარისხებული მასივით უნდა იყოს. `n!` ძალიან სწრაფად იზრდება: 9! 362 880-ია, 12! — 479 მილიონი, 15! კი უკვე წარმოუდგენლად დიდია.

## მოგზაური გამყიდველი
level: 4
tags: გადანაცვლებები, next_permutation, სრული გადარჩევა, მარშრუტი

გამყიდველი ქალაქ 1-დან გადის, ერთხელ სტუმრობს ყველა სხვა ქალაქს და ბრუნდება ქალაქ 1-ში. მოცემულია ქალაქებს შორის მანძილები (`d[i][j]` არის მანძილი `i`-დან `j`-მდე და შეიძლება `d[j][i]`-ისგან განსხვავდებოდეს). იპოვეთ უმოკლესი მარშრუტის სიგრძე.

### შეყვანა

პირველ ხაზზე `n`. შემდეგ `n` ხაზზე `n` რიცხვი: მანძილების ცხრილი (მთავარ დიაგონალზე ნულებია).

### გამოტანა

ერთი რიცხვი: უმოკლესი მარშრუტის სიგრძე.

### შეზღუდვები

### მაგალითი

```in
9 0 2

```

```out

```

### განმარტება

მარშრუტი 1 → 2 → 3 → 1: 1 + 2 + 3 = 6. საპირისპირო 1 → 3 → 2 → 1 უფრო გრძელია (27).

### მინიშნებები

1. ქალაქების სტუმრობის რიგი გადანაცვლებაა. რამდენი გადანაცვლებაა, თუ პირველი ქალაქი ფიქსირებულია?
2. დაფიქსირეთ ქალაქი 1 დასაწყისად და გაიარეთ დანარჩენ `n − 1` ქალაქის ყველა გადანაცვლება.
3. თითოეული გადანაცვლებისთვის ჯამეთ მანძილები თანმიმდევრულ ქალაქებს შორის და უკან ქალაქ 1-მდე. შეინახეთ მინიმუმი. `n = 1`-ზე მარშრუტი ცარიელია და სიგრძე 0-ია.

### ამოხსნა

```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<vector<int>> d(n, vector<int>(n));
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            cin >> d[i][j];
        }
    }
    vector<int> order(n - 1);
    iota(order.begin(), order.end(), 1);
    int best = 1 << 30;
    do {
        int total = 0;
        int city = 0;
        for (int next : order) {
            total += d[city][next];
            city = next;
        }
        total += d[city][0];
        best = min(best, total);
    } while (next_permutation(order.begin(), order.end()));
    cout << best << endl;
    return 0;
}
```

ქალაქ 1-ის (ინდექსი 0) ფიქსირებით გადანაცვლებათა რაოდენობა `n!`-დან `(n − 1)!`-მდე მცირდება: ამ ამოცანაში 7! = 5040. `n = 20`-ზე ეს გზა აღარ გამოდგებოდა: არსებობს ბევრად უფრო სწრაფი ამოხსნა ბიტმასკით და დინამიური პროგრამირებით (`O(2ⁿ n²)`), მაგრამ ის სცილდება ამ წიგნის ფარგლებს. ამოცანა „მოგზაური გამყიდველი“ ცნობილია: მისთვის სწრაფი უნივერსალური ამოხსნა უცნობია.

### სტრესი

```brute
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int n;
vector<vector<int>> d;
int best = 1 << 30;

void go(int city, int visited, int total) {
    if (visited == (1 << n) - 1) {
        best = min(best, total + d[city][0]);
        return;
    }
    for (int next = 0; next < n; next++) {
        if (!(visited & (1 << next))) go(next, visited | (1 << next), total + d[city][next]);
    }
}

int main() {
    cin >> n;
    d.assign(n, vector<int>(n));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++) cin >> d[i][j];
    go(0, 1, 0);
    cout << best << endl;
    return 0;
}
```
