weeks: 5

მასივი ერთნაირი ტიპის მრავალ მნიშვნელობას ერთ სახელს უწოდებს. ამ თავში ვიყენებთ `vector`-ს: ის ზომას თვითონ ინახავს და ზომა შეიძლება შეყვანიდან გავიგოთ. ვივარჯიშებთ ინდექსებზე, ჯამებზე, მრიცხველებზე, სწორ საზღვრებზე და ხშირ ხრიკებზე (პრეფიქსული ჯამები, წანაცვლება, ორი მაჩვენებელი).

წინაპირობა: ციკლები. ყველა ამოცანაში ინდექსები 0-დან იწყება პროგრამაში, მაგრამ პირობაში პოზიცია ხშირად 1-დან ითვლება: დააკვირდით, რომელ შემთხვევაშია ეს.

შეყვანის ფორმატი თითქმის ყველგან ერთნაირია: პირველ ხაზზე `n`, მეორე ხაზზე `n` რიცხვი.

## მასივი უკუღმა
level: 1
tags: vector, ციკლი, ინდექსი

წაიკითხეთ `n` რიცხვი და გამოიტანეთ ისინი საპირისპირო რიგით.

### შეყვანა

პირველ ხაზზე `n`. მეორე ხაზზე `n` მთელი რიცხვი.

### გამოტანა

იგივე რიცხვები საპირისპირო რიგით, ერთ ხაზზე.

### შეზღუდვები

1 ≤ n ≤ 1000, |რიცხვი| ≤ 10⁹

### მაგალითი

```in
5
1 2 3 4 5
```

```out
5 4 3 2 1
```

### შემოწმება

```in
1
42
```

```out
42
```

### მინიშნებები

1. ჯერ ყველა რიცხვი უნდა შეინახოთ: გამოტანას დასაწყისი მხოლოდ ბოლო რიცხვის წაკითხვის შემდეგ აქვს.
2. რიცხვები ჩაწერეთ `vector<int> a(n)`-ში. ბოლო ელემენტის ინდექსი `n - 1`-ია.
3. გამოიტანეთ ციკლით `i = n - 1`-დან 0-მდე, ბიჯით −1.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    for (int i = n - 1; i >= 0; i--) {
        cout << a[i] << " ";
    }
    cout << endl;
    return 0;
}
```

`vector<int> a(n)` ქმნის `n` ელემენტიან მასივს (თავიდან ნულებით). ინდექსები იწყება 0-დან და მთავრდება `n - 1`-ზე: `a[n]` უკვე გამოსავალია მასივიდან, პროგრამა შეიძლება უცნაურად იმუშაოს ან გაჩერდეს.

## უმცირესი და მისი ადგილი
level: 2
tags: vector, მინიმუმი, ინდექსი

იპოვეთ მასივის უმცირესი ელემენტი და მისი პოზიცია (პოზიცია 1-დან ითვლება). თუ უმცირესი რამდენჯერმე გვხვდება, გამოიტანეთ პირველი პოზიცია.

### შეყვანა

პირველ ხაზზე `n`. მეორე ხაზზე `n` მთელი რიცხვი.

### გამოტანა

ორი რიცხვი ერთ ხაზზე: უმცირესი ელემენტი და მისი პოზიცია.

### შეზღუდვები

1 ≤ n ≤ 10⁵, |რიცხვი| ≤ 10⁹

### მაგალითი

```in
5
4 2 7 2 9
```

```out
2 2
```

### შემოწმება

```in
1
5
```

```out
5 1
```

### მინიშნებები

1. ელემენტის გარდა, ინდექსიც უნდა გახსოვდეთ.
2. შეინახეთ მიმდინარე უმცირესის ინდექსი. ახალი ელემენტი უკეთესია, თუ **მკაცრად** უფრო პატარაა.
3. დაიწყეთ `best = 0`-დან; ციკლში `if (a[i] < a[best]) best = i;`. გამოიტანეთ `a[best]` და `best + 1`.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int best = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] < a[best]) {
            best = i;
        }
    }
    cout << a[best] << " " << best + 1 << endl;
    return 0;
}
```

მკაცრი შედარება `<` პირველ შემხვედრს ინახავს. თუ `<=` დაწერეთ, გამოვა **ბოლო** პოზიცია. ინდექსებს პროგრამაში 0-დან ვითვლით, პასუხისთვის კი 1 ვუმატებთ.

### სტრესი

```brute
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (auto &x : a) cin >> x;
    auto it = min_element(a.begin(), a.end());
    cout << *it << " " << (it - a.begin()) + 1 << endl;
    return 0;
}
```

## დადებითი, უარყოფითი, ნული

### შეყვანა

პირველ ხაზზე `n`. მეორე ხაზზე `n` მთელი რიცხვი.

### გამოტანა

სამი რიცხვი ერთ ხაზზე: დადებითების, უარყოფითების და ნულების რაოდენობა.


```out

```

### შემოწმება


### მინიშნებები

1. სამ ტიპს სამი მრიცხველი ესაჭიროება.
2. ყოველ ელემენტზე გადაწყვიტეთ ერთი რამ: დადებითია, უარყოფითია თუ ნული.
3. გამოიყენეთ `if / else if / else`. მასივში შენახვა არც არის საჭირო: ელემენტს წაკითხვისთანავე შეამოწმებთ.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int positive = 0, negative = 0, zero = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x > 0) {
            positive++;
        } else if (x < 0) {
            negative++;
        } else {
            zero++;
        }
    }
    cout << positive << " " << negative << " " << zero << endl;
    return 0;
}
```

ეს ამოხსნა მასივს საერთოდ არ ინახავს. თუ ელემენტის დამუშავება მხოლოდ წაკითხვისას შეიძლება და მასივი არ გვჭირდება, უმჯობესია არ შევქმნათ: მეხსიერება ეკონომდება და პროგრამა უფრო მარტივია.

## საშუალოზე დიდი
level: 2
tags: vector, საშუალო, დათვლა, long long

დაითვალეთ, რამდენი ელემენტია მასივის საშუალო არითმეტიკულზე **მკაცრად** მეტი.

### შეყვანა

პირველ ხაზზე `n`. მეორე ხაზზე `n` მთელი რიცხვი.

### გამოტანა

ერთი რიცხვი.

### შეზღუდვები

1 ≤ n ≤ 10⁵, |რიცხვი| ≤ 10⁹

### მაგალითი

```in
5
1 2 3 4 5
```

```out
2
```

### განმარტება

საშუალო არის 3; მასზე მეტია 4 და 5.

### მაგალითი

```in
3
2 2 2
```

```out
0
```

### შემოწმება

```in
2
-2 -1
```

```out
1
```

```in
2
1000000000 999999999
```

```out
1
```

### მინიშნებები

1. საშუალოს გამოსათვლელად ყველა რიცხვი უნდა გამოვიცნოთ: რა უნდა შეინახოთ?
2. ჯამი `n · 10⁹`-მდე შეიძლება იყოს. შეადარეთ `x` საშუალოს ისე, რომ გაყოფის დამრგვალება თავიდან აიცილოთ: `x * n > sum`.
3. მასივში შეინახეთ რიცხვები და ჯამი `long long`-ში. მეორე გავლაზე ითვლით ელემენტებს, რომლებისთვისაც `x * n > sum`.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        sum += a[i];
    }
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] * n > sum) {
            count++;
        }
    }
    cout << count << endl;
    return 0;
}
```

`x > sum / n` მთელი გაყოფით არასწორია: `-3 / 2` C++-ში `-1` არის, ანუ საშუალო `-1,5` არასწორად დამრგვალდება. უთანასწორობა `x · n > sum` იგივეა, რაც `x > sum / n` (n > 0) და გაყოფას თავიდან გვაცილებს. ტიპი `long long` აუცილებელია: `x · n` 10¹⁴-მდეა.

### სტრესი

```brute
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<double> a(n);
    double sum = 0;
    for (auto &x : a) {
        cin >> x;
        sum += x;
    }
    double avg = sum / n;
    int count = 0;
    for (double x : a) {
        if (x > avg + 1e-9) count++;
    }
    cout << count << endl;
    return 0;
}
```

## მნიშვნელობის წაშლა
level: 2
tags: vector, ფილტრი, ახალი მასივი

წაშალეთ მასივიდან ყველა ელემენტი, რომელიც `x`-ის ტოლია, და გამოიტანეთ დარჩენილი ელემენტები თავდაპირველი რიგით. თუ არაფერი დარჩა, გამოიტანეთ `EMPTY`.

### შეყვანა

პირველ ხაზზე `n`. მეორე ხაზზე `n` მთელი რიცხვი. მესამე ხაზზე `x`.

### გამოტანა

დარჩენილი ელემენტები ერთ ხაზზე ან `EMPTY`.

### შეზღუდვები

1 ≤ n ≤ 10⁵, |რიცხვი| ≤ 10⁹

### მაგალითი

```in
6
1 2 3 2 4 2
2
```

```out
1 3 4
```

### მაგალითი

```in
2
5 5
5
```

```out
EMPTY
```

### შემოწმება

```in
3
1 2 3
9
```

```out
1 2 3
```

### მინიშნებები

1. მასივიდან ელემენტის წაშლა რთულია, მაგრამ „საჭირო ელემენტებით ახალი მასივის აგება“ ადვილია.
2. გადაიარეთ ელემენტები; თუ ელემენტი `x`-ის ტოლი არ არის, ჩაამატეთ მეორე `vector`-ში `push_back`-ით.
3. ბოლოს შეამოწმეთ, ცარიელია თუ არა შედეგი (`result.empty()`).

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int x;
    cin >> x;
    vector<int> result;
    for (int i = 0; i < n; i++) {
        if (a[i] != x) {
            result.push_back(a[i]);
        }
    }
    if (result.empty()) {
        cout << "EMPTY" << endl;
    } else {
        for (int v : result) {
            cout << v << " ";
        }
        cout << endl;
    }
    return 0;
}
```

`push_back` ვექტორის ბოლოს ამატებს ელემენტს და ზომას ზრდის. „გაფილტვრა ახალ მასივში“ უფრო საიმედოა, ვიდრე ერთ მასივში ელემენტების წაშლა: წაშლისას ინდექსები იცვლება და ადვილია შეცდომა. ბოლო ციკლი `for (int v : result)` დიაპაზონული ციკლია (range-based for): ის ვექტორის ყველა ელემენტს მიყოლებით იღებს.

## განმეორებადი ელემენტი
level: 2
tags: vector, ეფექტურობა, დათვლა, მასივი-მრიცხველი

არის თუ არა მასივში ორი ერთნაირი ელემენტი? გამოიტანეთ `YES`, თუ რომელიმე რიცხვი ერთხელ მაინც განმეორდა, და `NO`, თუ ყველა განსხვავებულია.

### შეყვანა

პირველ ხაზზე `n`. მეორე ხაზზე `n` მთელი რიცხვი.

### გამოტანა

`YES` ან `NO`.

### შეზღუდვები

1 ≤ n ≤ 10⁵, 1 ≤ რიცხვი ≤ 10⁶

### მაგალითი

```in
5
1 2 3 2 5
```

```out
YES
```

### მაგალითი

```in

1 2 3
```

```out
NO
```

### შემოწმება

```in

```


### მინიშნებები

1. ყველა წყვილის შედარება `n = 10⁵`-ზე 5 მილიარდ შედარებას მოითხოვს. ეს ძალიან ბევრია.
2. რიცხვები არც ისე დიდია (≤ 10⁶). შეგიძლიათ მასივში მონიშნოთ, რომელი რიცხვები უკვე ნახეთ.
3. შექმენით `vector<bool> seen(1000001)`. ყოველი რიცხვისთვის: თუ `seen[x]` უკვე `true`-ა, პასუხია `YES`; წინააღმდეგ შემთხვევაში `seen[x] = true`.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<bool> seen(1000001, false);
    bool duplicate = false;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (seen[x]) {
            duplicate = true;
        }
        seen[x] = true;
    }
    cout << (duplicate ? "YES" : "NO") << endl;
    return 0;
}
```

რიცხვი თავად ხდება მასივის ინდექსი: `seen[x]` პასუხობს „ვნახე თუ არა `x`?“. ეს მეთოდი სწრაფია (ერთი გავლა), მაგრამ მუშაობს იმიტომ, რომ რიცხვები მცირეა. რიცხვები რომ 10⁹-მდე ყოფილიყო, საჭირო იქნებოდა დახარისხება ან `set`.

### სტრესი

```brute
#include <iostream>
#include <vector>

    int n;

    bool duplicate = false;

        for (int j = i + 1; j < n; j++) {
            if (a[i] == a[j]) duplicate = true;
        }
    }

    return 0;
}
```

### მინიშნებები

1. დახარისხების გარეშეც შეიძლება: უდიდესს ეძებთ და გზაში მეორესაც.
2. შეინახეთ ორი მნიშვნელობა: უდიდესი `first` და მისი მომდევნო `second`. ახალი `x` ორივეს ეხება.
3. თუ `x > first`: `second = first; first = x`. თუ `x < first` და `x > second`: `second = x`. თუ `x == first`, არაფერი ხდება. საწყისისთვის გამოიყენეთ `long long`-ის „მინუს უსასრულობა“ (მაგალითად, `-4e18`).

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    const long long NONE = -4000000000000000000LL;
    long long first = NONE, second = NONE;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (x > first) {
            second = first;
            first = x;
        } else if (x < first && x > second) {
            second = x;
        }
    }
    if (second == NONE) {
        cout << "NONE" << endl;
    } else {
        cout << second << endl;
    }
    return 0;
}
```

საწყისი მნიშვნელობა („არაფერი ჯერ არ არის“) არჩეულია ისე, რომ ნებისმიერი რეალური რიცხვი მასზე დიდი იყოს. ტოლი ელემენტები მეორეს არ ცვლის: ამიტომ `9 9 7` გვაძლევს 7-ს და არა 9-ს. საკმარისია გავიდეთ მასივზე ერთხელ.

## პრეფიქსული ჯამები

tags: vector, პრეფიქსული ჯამი, შეკითხვები, ეფექტურობა

მოცემულია მასივი და `q` შეკითხვა. ყოველი შეკითხვა ითხოვს ელემენტების ჯამს `l`-დან `r`-მდე პოზიციებზე (ორივე ჩათვლით, პოზიციები 1-დან).

### შეყვანა

პირველ ხაზზე `n` და `q`. მეორე ხაზზე `n` მთელი რიცხვი. შემდეგ `q` ხაზზე თითო შეკითხვა: `l r`.

### შეზღუდვები

### მაგალითი



### მინიშნებები

1. თითოეული შეკითხვის ნაწილებით დათვლა 10⁵ · 10⁵ ოპერაციას მოითხოვს. ეს ბევრია.
2. წინასწარ დათვალეთ ჯამები „დასაწყისიდან `i`-მდე“ ყოველი `i`-სთვის. მაშინ ორი ასეთი ჯამის სხვაობა გვაძლევს ნებისმიერ მონაკვეთს.
3. `pre[i] = pre[i - 1] + a[i]`, `pre[0] = 0`. პასუხი `[l, r]`-ზე არის `pre[r] - pre[l - 1]`. ტიპი: `long long`.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<long long> pre(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        pre[i] = pre[i - 1] + x;
    }
    for (int i = 0; i < q; i++) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << "\n";
    }
    return 0;
}
```

წინასწარი გამოთვლა ერთხელ ჯდება, შემდეგ ყოველი შეკითხვა ერთ ოპერაციად. `pre[0] = 0` დამატებითი უჯრა გვარიდებს განსაკუთრებულ შემთხვევას `l = 1`-ზე. ეს იდეა ბევრჯერ გამოგადგებათ: „ბევრი შეკითხვა, ერთი მასივი“.

2. ჩადგმული ციკლი: `i` 0-დან `n - 1`-მდე, `j` `i + 1`-დან `n - 1`-მდე. მაშინ ყოველ წყვილს ზუსტად ერთხელ ვნახავთ.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
```

### მინიშნებები

1. `k` შეიძლება `n`-ზე ბევრად დიდი იყოს. რა იცვლება, როცა მასივს `n` პოზიციით გადასწევთ?
2. `n` პოზიციით წანაცვლება მასივს აბრუნებს თავდაპირველ მდგომარეობაში. ამიტომ საკმარისია `k % n`.
3. ახალ მასივში ელემენტი, რომელიც `i` პოზიციაზე იყო, გადადის `(i + k) % n` პოზიციაზე.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    long long k;
    cin >> n >> k;
    vector<int> a(n), b(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int shift = k % n;
    for (int i = 0; i < n; i++) {
        b[(i + shift) % n] = a[i];
    }
    for (int i = 0; i < n; i++) {
        cout << b[i] << " ";
    }
    cout << endl;
    return 0;
}
```

წანაცვლება `n`-ის ჯერადით არაფერს ცვლის, ამიტომ `k`-ს ვამცირებთ `k % n`-ით და ციკლი აღარ გვჭირდება 10⁹-ჯერ. ოპერატორი `%` აქ ციკლურობას გამოხატავს: პოზიცია `n`-ის შემდეგ ისევ 0 ხდება.

### სტრესი

```brute
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (auto &x : a) cin >> x;
    for (int step = 0; step < k; step++) {
        int last = a[n - 1];
        for (int i = n - 1; i > 0; i--) a[i] = a[i - 1];
        a[0] = last;
    }
    for (int x : a) cout << x << " ";
    cout << endl;
    return 0;
}
```

## ორი დახარისხებული მასივის შერწყმა
level: 3
tags: vector, ორი მაჩვენებელი, შერწყმა

მოცემულია ორი ზრდადობით დახარისხებული მასივი. შეადგინეთ ერთი დახარისხებული მასივი, რომელიც ორივეს ყველა ელემენტს შეიცავს. ეცადეთ, ახალი დახარისხება არ გამოიყენოთ.

### შეყვანა

პირველ ხაზზე `n` და `m`. მეორე ხაზზე `n` რიცხვი (ზრდადობით). მესამე ხაზზე `m` რიცხვი (ზრდადობით).

### გამოტანა

`n + m` რიცხვი ზრდადობით, ერთ ხაზზე.

### შეზღუდვები

1 ≤ n, m ≤ 10⁵, |რიცხვი| ≤ 10⁹

### მაგალითი

```in
3 2
1 4 9
2 3
```

```out
1 2 3 4 9
```

### მაგალითი

```in
2 2
1 1
1 1
```

```out
1 1 1 1
```

### შემოწმება

```in
1 3
10
1 2 3
```

```out

```

### მინიშნებები

1. რომელი ელემენტი იქნება შედეგში პირველი? რომელი იქნება მეორე?
2. შეინახეთ ორი მაჩვენებელი, `i` და `j`: შეადარეთ `a[i]` და `b[j]`, პატარა გადაიტანეთ შედეგში და მისი მაჩვენებელი წაწიეთ.
3. როცა ერთი მასივი ამოიწურება, მეორის დარჩენილი ელემენტები პირდაპირ გადაიტანეთ.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<int> a(n), b(m);
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int j = 0; j < m; j++) cin >> b[j];
    int i = 0, j = 0;
    while (i < n || j < m) {
        if (j == m || (i < n && a[i] <= b[j])) {
            cout << a[i++] << " ";
        } else {
            cout << b[j++] << " ";
        }
    }
    cout << endl;
    return 0;
}
```

ყოველი ელემენტი ზუსტად ერთხელ განიხილება, ამიტომ ოპერაციების რაოდენობა `n + m`-ია, დახარისხება კი `(n + m) log(n + m)`-ს მოითხოვდა. პირობაში `j == m ||` ამოწმებს, რომ მეორე მასივი ამოიწურა; ასეთ დროს `b[j]`-ს არ ვეხებით (ის უკვე გასცდა). ეს არის „შერწყმა“, დახარისხების ალგორითმი `merge sort`-ის ძირითადი ნაბიჯი.

### სტრესი

```brute
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<int> all(n + m);
    for (auto &x : all) cin >> x;
    sort(all.begin(), all.end());
    for (int x : all) cout << x << " ";
    cout << endl;
    return 0;
}
```

## უდიდესი ქვემასივის ჯამი
level: 4
tags: vector, კადანეს ალგორითმი, ეფექტურობა, ქვემასივი

ქვემასივი არის მასივის ზედიზედ მდგარი ელემენტების არაცარიელი მონაკვეთი. იპოვეთ ისეთი ქვემასივი, რომლის ელემენტების ჯამი უდიდესია, და გამოიტანეთ ეს ჯამი.

### შეყვანა

პირველ ხაზზე `n`. მეორე ხაზზე `n` მთელი რიცხვი.

### მინიშნებები

1. ყველა ქვემასივის შემოწმება `n²` გამოთვლას მოითხოვს. იფიქრეთ, როგორ გამოიყენოთ წინა ელემენტზე დასრულებული ქვემასივი.
2. თითოეულ პოზიციაზე ორი არჩევანია: დაიწყოთ ახალი ქვემასივი აქ ან გააგრძელოთ წინა. გაგრძელება მხოლოდ მაშინ ღირს, თუ წინა ჯამი დადებითია.
3. შეინახეთ `cur` (უდიდესი ჯამი, რომელიც მიმდინარე ელემენტზე მთავრდება) და `best`. `cur = max(x, cur + x)`, `best = max(best, cur)`. პირველი ელემენტიდან დაიწყეთ, რადგან ქვემასივი არაცარიელია.

### ამოხსნა

```cpp
#include <algorithm>
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long cur = 0, best = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (i == 0) {
            cur = best = x;
        } else {
            cur = max(x, cur + x);
            best = max(best, cur);
        }
    }
    cout << best << endl;
    return 0;
}
```

თუ წინა ჯამი უარყოფითია, ის მხოლოდ ზარალს მოიტანს და უმჯობესია ახალი ქვემასივი დავიწყოთ. ეს არის კადანეს ალგორითმი: ერთი გავლა, `O(n)`. თუ ყველა ელემენტი უარყოფითია, პასუხი უდიდესი ელემენტია (მეორე მაგალითი): ამიტომ `best` ნულიდან კი არა, პირველი ელემენტიდან იწყება.

### სტრესი

```brute
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    long long best = a[0];
    for (int i = 0; i < n; i++) {
        long long s = 0;
        for (int j = i; j < n; j++) {
            s += a[j];
            if (s > best) best = s;
        }
    }
    cout << best << endl;
    return 0;
}
```
