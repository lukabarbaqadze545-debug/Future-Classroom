# თავი 13. რეკურსია
weeks: 9

რეკურსია ფუნქციის გამოძახებას ნიშნავს თავად ამ ფუნქციის შიგნიდან. ყოველი რეკურსიული ფუნქცია ორი ნაწილისგან შედგება: **ბაზისური შემთხვევა** (როდის ჩერდება) და **რეკურსიული ნაბიჯი** (როგორ დაიყვანება ამოცანა უფრო მცირე ამოცანაზე). თუ ბაზისური შემთხვევა დაგავიწყდებათ, ფუნქცია უსასრულოდ გამოიძახებს თავს და პროგრამა გაჩერდება.

რეკურსიით ბუნებრივად იხსნება ამოცანები, სადაც დიდი ამოცანა მსგავს პატარა ამოცანებად იშლება: ფაქტორიალი, ჰანოის კოშკები, ქვესიმრავლეები და გადანაცვლებები, გადარჩევა ჭრით (backtracking). ამ თავში ვივარჯიშებთ რეკურსიის გაგებაში და სხვადასხვა ტიპის გადარჩევის დაწერაში.

წინაპირობა: ფუნქციები (მე-5 თავი) და სირთულის შეფასება (მე-10 თავი). რეკურსიის გასაგებად ხელით გაიარეთ პატარა მაგალითი და ჩაიწერეთ, რომელი გამოძახება რას აბრუნებს.

## რეკურსიის კვალი
level: 2
kind: predict
tags: ვარაუდი, რეკურსია, გამოძახებების სტეკი

რას დაბეჭდავს ეს პროგრამა?

```cpp
#include <iostream>
using namespace std;

void f(int n) {
    if (n == 0) {
        return;
    }
    cout << n << " ";
    f(n - 1);
    cout << n << " ";
}

int main() {
    f(3);
    cout << endl;
    return 0;
}
```

### მინიშნებები

1. დახაზეთ გამოძახებათა ჯაჭვი: `f(3)` იძახებს `f(2)`-ს, რომელიც `f(1)`-ს და ა. შ.
2. ყოველი გამოძახება ორჯერ ბეჭდავს: რეკურსიულ გამოძახებამდე და მის შემდეგ.

### ამოხსნა

```out
3 2 1 1 2 3
```

`f(3)` დაბეჭდავს 3-ს, შემდეგ იძახებს `f(2)`-ს (რომელიც 2-ს, შემდეგ `f(1)`-ს, რომელიც 1-ს ბეჭდავს და `f(0)`-ს იძახებს: ის მაშინვე ბრუნდება). შემდეგ ყოველი გამოძახება თავის მეორე `cout`-ს ასრულებს უკუ რიგით: 1, 2, 3. გამოძახებები „სტეკში“ დაგროვდება და ბოლოს უკუღმა იხსნება.

## ფაქტორიალი რეკურსიით
level: 2
tags: რეკურსია, ფაქტორიალი, ბაზისური შემთხვევა

გამოთვალეთ `n!` რეკურსიული ფუნქციით: `n! = n · (n − 1)!`, ხოლო `0! = 1`.

### შეყვანა

ერთი მთელი რიცხვი `n`.

### გამოტანა

ერთი რიცხვი: `n!`.

### შეზღუდვები

0 ≤ n ≤ 20

### მაგალითი

```in
5
```

```out
120
```

### მაგალითი

```in
0
```

```out
1
```

### შემოწმება

```in
20
```

```out
2432902008176640000
```

### მინიშნებები

1. ამოცანა დაიყვანეთ უფრო პატარა იგივე ამოცანაზე.
2. `n! = n · (n − 1)!`. რა გააჩერებს გამოძახებათა ჯაჭვს?
3. ფუნქცია `long long fact(int n)`: თუ `n == 0` დააბრუნეთ 1; წინააღმდეგ შემთხვევაში `n * fact(n - 1)`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

long long fact(int n) {
    if (n == 0) {
        return 1;
    }
    return n * fact(n - 1);
}

int main() {
    int n;
    cin >> n;
    cout << fact(n) << endl;
    return 0;
}
```

ბაზისური შემთხვევა `n == 0` ჯაჭვს ამთავრებს. ყოველი გამოძახება `n`-ს ერთით ამცირებს და ბოლოს აუცილებლად 0-ს აღწევს. მაგალითად, `fact(3)` = `3 * fact(2)` = `3 * (2 * fact(1))` = `3 * (2 * (1 * fact(0)))` = `3 * 2 * 1 * 1`. რეკურსია ციკლის ალტერნატივაა: ფაქტორიალისთვის ციკლი უფრო მარტივიც არის, მაგრამ აქ მიზანი რეკურსიის გაგებაა.

## ციფრების ჯამი რეკურსიით
level: 2
tags: რეკურსია, ციფრები, %

გამოთვალეთ რიცხვის ციფრების ჯამი რეკურსიით, ციკლის გარეშე.

### შეყვანა

ერთი მთელი არაუარყოფითი რიცხვი `n`.

### გამოტანა

ერთი რიცხვი: ციფრების ჯამი.

### შეზღუდვები

0 ≤ n ≤ 10¹⁸

### მაგალითი

```in
12345
```

```out
15
```

### შემოწმება

```in
0
```

```out
0
```

```in
999999999999999999
```

```out
162
```

### მინიშნებები

1. რიცხვის ციფრების ჯამი ბოლო ციფრისა და დარჩენილი რიცხვის ციფრების ჯამის ჯამია.
2. ბოლო ციფრი: `n % 10`, დარჩენილი რიცხვი: `n / 10`.
3. `digitSum(0) = 0`, წინააღმდეგ შემთხვევაში `digitSum(n) = n % 10 + digitSum(n / 10)`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

int digitSum(long long n) {
    if (n == 0) {
        return 0;
    }
    return n % 10 + digitSum(n / 10);
}

int main() {
    long long n;
    cin >> n;
    cout << digitSum(n) << endl;
    return 0;
}
```

ეს პირველი თავის იდეაა, რეკურსიულად ჩაწერილი: ყოველი გამოძახება ერთ ციფრს „ჭამს“. სიღრმე ციფრების რაოდენობის ტოლია (19-მდე), ამიტომ გამოძახებათა სტეკი არ გადაივსება. რეკურსიის სიღრმე ათასობით ან მილიონობით რომ ყოფილიყო, პროგრამა შეიძლება მეხსიერების გამო გაჩერებულიყო.

## უდიდესი საერთო გამყოფი რეკურსიით
level: 2
tags: რეკურსია, ევკლიდეს ალგორითმი

იპოვეთ ორი რიცხვის უდიდესი საერთო გამყოფი რეკურსიული ფუნქციით: `gcd(a, b) = gcd(b, a % b)`, ხოლო `gcd(a, 0) = a`.

### შეყვანა

ერთ ხაზზე ორი მთელი დადებითი რიცხვი `a` და `b`.

### გამოტანა

ერთი რიცხვი.

### შეზღუდვები

1 ≤ a, b ≤ 10¹⁸

### მაგალითი

```in
12 18
```

```out
6
```

### შემოწმება

```in
17 5
```

```out
1
```

```in
5 17
```

```out
1
```

### მინიშნებები

1. ევკლიდეს ალგორითმი ბუნებრივად რეკურსიულია: ყოველი ნაბიჯი ამოცანას იგივე ამოცანაზე ამცირებს.
2. ბაზისური შემთხვევა: როცა მეორე რიცხვი ნულია, პასუხი პირველია.
3. `long long gcd(long long a, long long b) { if (b == 0) return a; return gcd(b, a % b); }`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

long long gcd(long long a, long long b) {
    if (b == 0) {
        return a;
    }
    return gcd(b, a % b);
}

int main() {
    long long a, b;
    cin >> a >> b;
    cout << gcd(a, b) << endl;
    return 0;
}
```

ეს არის მე-4 თავის ციკლური ამოხსნის იდენტური მეთოდი, მხოლოდ რეკურსიით ჩაწერილი. გამოძახებათა სიღრმე ლოგარითმულია (ათეულობით), ამიტომ ეს რეკურსია უსაფრთხოა 10¹⁸-ზეც.

## ფიბონაჩი და გამოძახებები
level: 3
tags: რეკურსია, ფიბონაჩი, ექსპონენციალური სირთულე

ფიბონაჩის რიცხვები ასე განისაზღვრება: `F(1) = F(2) = 1`, `F(n) = F(n − 1) + F(n − 2)`. გამოთვალეთ `F(n)` უშუალოდ ამ განსაზღვრებით (რეკურსიულად) და დაითვალეთ, რამდენჯერ გამოიძახეთ ფუნქცია სულ.

### შეყვანა

ერთი მთელი რიცხვი `n`.

### გამოტანა

ორი რიცხვი ერთ ხაზზე: `F(n)` და ფუნქციის გამოძახებების რაოდენობა.

### შეზღუდვები

1 ≤ n ≤ 30

### მაგალითი

```in
5
```

```out
5 9
```

### განმარტება

`F(5)` იძახებს `F(4)`-ს და `F(3)`-ს და ა. შ.: სულ 9 გამოძახება (პირველის ჩათვლით).

### მაგალითი

```in
1
```

```out
1 1
```

### შემოწმება

```in
30
```

```out
832040 1664079
```

### მინიშნებები

1. დაწერეთ ფუნქცია, რომელიც განსაზღვრებას პირდაპირ იმეორებს. გამოძახებების რაოდენობის დასათვლელად გლობალური მრიცხველი დაგჭირდებათ.
2. მრიცხველი გაზარდეთ ფუნქციაში სულ პირველივე სტრიქონზე, ბაზისურ შემთხვევამდე.
3. `fib(n)`: მრიცხველი++; თუ `n <= 2`, დააბრუნეთ 1; წინააღმდეგ შემთხვევაში `fib(n - 1) + fib(n - 2)`.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

long long calls = 0;

long long fib(int n) {
    calls++;
    if (n <= 2) {
        return 1;
    }
    return fib(n - 1) + fib(n - 2);
}

int main() {
    int n;
    cin >> n;
    long long result = fib(n);
    cout << result << " " << calls << endl;
    return 0;
}
```

გამოძახებათა რაოდენობა ძალიან სწრაფად იზრდება: `n = 30`-ზე 1,6 მილიონზე მეტია, `n = 50`-ზე კი ათეულობით მილიარდი იქნებოდა. მიზეზი: ერთსა და იმავე `F(k)`-ს ბევრჯერ ვითვლით. მაგალითად, `F(5)`-ში `F(3)` ორჯერ ითვლება. ამიტომ დიდ `n`-ზე ფიბონაჩის რიცხვებს ციკლით ან „დინამიური პროგრამირებით“ ვითვლით: ეს მე-14 თავში გაქვთ.

## ჰანოის კოშკები
level: 3
tags: რეკურსია, ჰანოის კოშკები, გამოტანის ფორმატი

სამი ღერძია: 1, 2 და 3. პირველ ღერძზე `n` დისკო გიდევს, ყველაზე დიდი ქვემოთაა. უნდა გადაიტანოთ ყველა დისკო მესამე ღერძზე. ყოველ სვლაზე შეიძლება ერთი (ზედა) დისკოს გადატანა ერთი ღერძიდან მეორეზე; დიდი დისკო პატარაზე არასოდეს დაიდება. იპოვეთ უმცირესი რაოდენობის სვლა და ჩამოწერეთ ისინი.

### შეყვანა

ერთი მთელი რიცხვი `n`.

### გამოტანა

პირველ ხაზზე სვლების რაოდენობა. შემდეგ ყოველ ხაზზე ერთი სვლა: ორი რიცხვი, საიდან და სად.

### შეზღუდვები

### მინიშნებები

1. წარმოიდგინეთ, რომ ზედა `n − 1` დისკოს გადატანა თქვენთვის უკვე იცით. როგორ დაგეხმარებათ ეს უდიდეს დისკოსთან?
2. სამი ნაბიჯი: ზედა `n − 1` დისკო გადაიტანეთ დამხმარე ღერძზე, უდიდესი გადაიტანეთ მიზანზე, ზედა `n − 1` დისკო დამხმარედან მიზანზე.
3. `hanoi(n, from, to, via)`: თუ `n == 0`, არაფერი. `hanoi(n − 1, from, via, to)`; დაბეჭდეთ `from to`; `hanoi(n − 1, via, to, from)`. სვლების რაოდენობა `2ⁿ − 1`-ია.

### ამოხსნა

```cpp
#include <iostream>
using namespace std;

void hanoi(int n, int from, int to, int via) {
    if (n == 0) {
        return;
    }
    hanoi(n - 1, from, via, to);
    cout << from << " " << to << "\n";
    hanoi(n - 1, via, to, from);
}

int main() {
    int n;
    cin >> n;
    cout << (1 << n) - 1 << "\n";
    hanoi(n, 1, 3, 2);
    return 0;
}
```

დიდი ამოცანა სამ პატარა ამოცანად იშლება, რომელთაგან ორი იგივე ამოცანაა, ოღონდ `n − 1` დისკოთი. სვლების რაოდენობა `T(n) = 2T(n − 1) + 1`, ანუ `2ⁿ − 1`: ამიტომ `n = 64`-ისთვის სვლები მილიარდობით წელიწადს მოითხოვს. ეს ამოცანა რეკურსიის კლასიკური მაგალითია: ამოხსნა შეიძლება იყოს ძალიან მოკლე და მაინც რთული წარმოსადგენი ციკლებით.

## ყველა არაცარიელი ქვესიმრავლე

გამოიტანეთ რიცხვთა სიმრავლის `{1, 2, …, n}` ყველა არაცარიელი ქვესიმრავლე. თითოეული ქვესიმრავლე ჩაწერეთ ზრდადობით, ხოლო ქვესიმრავლეები დაალაგეთ ლექსიკოგრაფიულად (ისე, როგორც ლექსიკონში სიტყვები).

### შეყვანა

### გამოტანა

### შეზღუდვები

1 ≤ n ≤ 10

### მაგალითი


```out
1
1 2
1 2 3
1 3
2
2 3
3
```

### შემოწმება

```in
1
```

```out
1
```

### მინიშნებები

1. ყოველი ქვესიმრავლე შეიძლება ავაგოთ ელემენტ-ელემენტად, ზრდადობით.
2. დაიმახსოვრეთ მიმდინარე ქვესიმრავლე ვექტორში. რეკურსიული ფუნქცია იღებს „საიდან დავიწყოთ“ რიცხვს და ყოველ შემდეგ ელემენტს ცდის.
3. `go(start)`: `i`-ისთვის `start`-დან `n`-მდე: ჩაამატეთ `i`, დაბეჭდეთ ქვესიმრავლე, გამოიძახეთ `go(i + 1)`, მოაცილეთ `i` (უკან დაბრუნება).

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int n;
vector<int> current;

void go(int start) {
    for (int i = start; i <= n; i++) {
        current.push_back(i);
        for (size_t k = 0; k < current.size(); k++) {
            cout << current[k] << (k + 1 < current.size() ? " " : "\n");
        }
        go(i + 1);
        current.pop_back();
    }
}

int main() {
    cin >> n;
    go(1);
    return 0;
}
```

ეს „გადარჩევა უკან დაბრუნებით“ (backtracking): ელემენტს ვამატებთ, რეკურსიით ვაგრძელებთ, შემდეგ ვაბრუნებთ ისეთ მდგომარეობას, როგორიც იყო (`pop_back`), რომ შემდეგი ვარიანტი სუფთა სიიდან დავიწყოთ. ბრძანებათა ასეთი რიგი ბუნებრივად იძლევა ლექსიკოგრაფიულ რიგს.

## ყველა გადანაცვლება

გამოიტანეთ რიცხვების `1, 2, …, n` ყველა გადანაცვლება ლექსიკოგრაფიული (ანბანური) რიგით.

### გამოტანა

### შეზღუდვები

### მინიშნებები

1. გადანაცვლება არის რიცხვების განლაგების რიგი. ყოველ პოზიციაზე ვცდით ყველა რიცხვს, რომელიც ჯერ არ გამოვიყენეთ.
2. შეინახეთ მასივი `used[]`, რომელიც აღნიშნავს, რომელი რიცხვები უკვე გამოიყენეს. რიცხვები მიმდევრობით ზრდადობით ივლის, ამიტომ რიგი ლექსიკოგრაფიული გამოვა.
3. `go(position)`: თუ `position == n`, დაბეჭდეთ. წინააღმდეგ შემთხვევაში ყოველი გამოუყენებელი `v`-სთვის: ჩაწერეთ `perm[position] = v`, მონიშნეთ, გამოიძახეთ `go(position + 1)`, მოხსენით ნიშანი.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int n;
vector<int> perm;
vector<bool> used;

void go(int position) {
    if (position == n) {
        for (int i = 0; i < n; i++) {
            cout << perm[i] << (i + 1 < n ? " " : "\n");
        }
        return;
    }
    for (int v = 1; v <= n; v++) {
        if (used[v]) {
            continue;
        }
        used[v] = true;
        perm[position] = v;
        go(position + 1);
        used[v] = false;
    }
}

int main() {
    cin >> n;
    perm.assign(n, 0);
    used.assign(n + 1, false);
    go(0);
    return 0;
}
```

ნიშნის მოხსნა (`used[v] = false`) უკან დაბრუნებაა: როცა ამ ვარიანტს გავცდებით, `v` ხელახლა ხელმისაწვდომია სხვა განლაგებისთვის. `n = 7`-ზე 5040 გადანაცვლებაა. ბიბლიოთეკური `next_permutation` იმავეს აკეთებს, მაგრამ რეკურსიული გადარჩევა მოქნილია: აქ ნებისმიერი დამატებითი პირობა ჩადგება და ზედმეტი ვარიანტები ადრე მოიჭრება.

## ქვესიმრავლის ჯამი
level: 3
tags: რეკურსია, გადარჩევა, ქვესიმრავლეები

არსებობს თუ არა მოცემული რიცხვებიდან ისეთი ქვესიმრავლე (შეიძლება ცარიელიც), რომლის ჯამი ზუსტად `S`-ია? გამოიტანეთ `YES` ან `NO`.

### შეყვანა

პირველ ხაზზე `n` და `S`. მეორე ხაზზე `n` რიცხვი.

### გამოტანა

### მაგალითი

```in
3 34 4 12 5 2
```

```out

```

### მაგალითი

```in
3 100
1 2 3
```

```out

```

### შემოწმება

```in

5
```

```out

```

### მინიშნებები

1. ყოველი რიცხვისთვის ორი არჩევანია: ავიღოთ თუ არა.
2. `can(i, left)`: შესაძლებელია თუ არა ელემენტებიდან `i`, `i + 1`, …, `n − 1` დანარჩენი `left` ჯამის შეგროვება.
3. ბაზისური შემთხვევა: `left == 0` არის `true`; თუ `i == n`, `false`. წინააღმდეგ შემთხვევაში: `can(i + 1, left)` (არ ვიღებთ) ან `a[i] <= left && can(i + 1, left - a[i])` (ვიღებთ).

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int n;
vector<long long> a;

bool can(int i, long long left) {
    if (left == 0) {
        return true;
    }
    if (i == n) {
        return false;
    }
    if (can(i + 1, left)) {
        return true;
    }
    return a[i] <= left && can(i + 1, left - a[i]);
}

int main() {
    long long S;
    cin >> n >> S;
    a.resize(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    cout << (can(0, S) ? "YES" : "NO") << endl;
    return 0;
}
```

ყოველ საფეხურზე ორი ტოტია, ამიტომ უარეს შემთხვევაში `2ⁿ` გამოძახებაა, მაგრამ ადრეული გამოსვლები (`return true`, `a[i] <= left`) ხშირად ბევრ ტოტს მოაჭრის. რეკურსია სწორედ ამით ამარტივებს გადარჩევას: ბიტმასკით ყველა ქვესიმრავლე უნდა გადაგვევლო, აქ კი შეგვიძლია მოვჭრათ ტოტი, თუ ის უკვე უიმედოა.

### სტრესი

```brute
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    long long S;
    cin >> n >> S;
    vector<long long> a(n);
    for (auto &x : a) cin >> x;
    bool found = false;
    for (int mask = 0; mask < (1 << n); mask++) {
        long long sum = 0;
        for (int i = 0; i < n; i++) if (mask & (1 << i)) sum += a[i];
        if (sum == S) found = true;
    }
    cout << (found ? "YES" : "NO") << endl;
    return 0;
}
```

## სწორი ფრჩხილების მიმდევრობები
level: 4
tags: რეკურსია, გადარჩევა ჭრით, ფრჩხილები

გამოიტანეთ ყველა სწორი ფრჩხილების მიმდევრობა, რომელიც `n` წყვილ ფრჩხილს შეიცავს, ლექსიკოგრაფიულად (სიმბოლო `(` ითვლება `)`-ზე ადრე). მიმდევრობა სწორია, თუ ყოველ დამხურავს შეესაბამება წინა გამხსნელი.

### მინიშნებები

1. სიგრძე `2n`-ია. ყოველ პოზიციაზე ორი არჩევანი გაქვთ: `(` ან `)`. ყველა ვარიანტიდან უმეტესობა არასწორია.
2. გამხსნელი შეიძლება ჩაიწეროს, თუ ჯერ `n`-ზე ნაკლები გამხსნელი გამოვიყენეთ. დამხურავი შეიძლება ჩაიწეროს, თუ ის გახსნილ, მაგრამ ჯერ დაუხურავ ფრჩხილებზე მეტი არ იქნება.
3. `go(open, close)` ინახავს, რამდენი გამხსნელი და დამხურავი დავწერეთ. თუ `open == n` და `close == n`, დაბეჭდეთ. თუ `open < n`, სცადეთ `(` (ჯერ ეს, რომ რიგი ლექსიკოგრაფიული იყოს); თუ `close < open`, სცადეთ `)`.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
using namespace std;

int n;
string current;

void go(int open, int close) {
    if (open == n && close == n) {
        cout << current << "\n";
        return;
    }
    if (open < n) {
        current.push_back('(');
        go(open + 1, close);
        current.pop_back();
    }
    if (close < open) {
        current.push_back(')');
        go(open, close + 1);
        current.pop_back();
    }
}

int main() {
    cin >> n;
    go(0, 0);
    return 0;
}
```

ეს გადარჩევა „ჭრით“: არასწორი პრეფიქსის (მაგალითად, `())`) გაგრძელებას საერთოდ არ ვცდილობთ, ამიტომ ვარიანტების რაოდენობა `2²ⁿ`-ის ნაცვლად მხოლოდ სწორი მიმდევრობების რაოდენობაა (`n = 10`-ზე 16 796). წესი `close < open` გვაძლევს მხოლოდ სწორ მიმდევრობებს. ამავე პრობლემაზე სტეკით შემოწმება წინა თავში გქონდათ: ეს მისი „გენერაციული“ ვარიანტია.

### სტრესი

```brute
#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    int len = 2 * n;
    for (int mask = 0; mask < (1 << len); mask++) {
        string s;
        for (int bit = len - 1; bit >= 0; bit--) s += ((mask >> bit) & 1) ? ')' : '(';
        int balance = 0;
        bool ok = true;
        for (char c : s) {
            balance += c == '(' ? 1 : -1;
            if (balance < 0) ok = false;
        }
        if (ok && balance == 0) cout << s << "\n";
    }
    return 0;
}
```

## გზები ბადეზე
level: 4
tags: რეკურსია, ბადე, გზების დათვლა

მოცემულია ბადე `n × m`. უჯრა `.` თავისუფალია, `#` დაბრკოლებაა. გადადით ზედა მარცხენა უჯრიდან ქვედა მარჯვენაში, ყოველ ნაბიჯზე ერთი უჯრით მარჯვნივ ან ერთი უჯრით ქვემოთ, დაბრკოლებაში გავლის გარეშე. დაითვალეთ, რამდენი განსხვავებული გზა არსებობს.

### მინიშნებები

1. მოცემულ უჯრაში გზების რაოდენობა ორი შესაძლო წინა უჯრიდან მოდის. პირიქით, მოცემული უჯრიდან გზების რაოდენობა ორი შემდეგი უჯრიდან მოდის.
2. `paths(i, j)`: გზების რაოდენობა `(i, j)`-დან ქვედა მარჯვენა უჯრამდე.
3. თუ `(i, j)` ბადის გარეთაა ან `#`-ია, დააბრუნეთ 0. თუ ის ქვედა მარჯვენა უჯრაა, დააბრუნეთ 1. სხვა შემთხვევაში `paths(i + 1, j) + paths(i, j + 1)`.

### ამოხსნა

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int n, m;
vector<string> grid;

long long paths(int i, int j) {
    if (i >= n || j >= m || grid[i][j] == '#') {
        return 0;
    }
    if (i == n - 1 && j == m - 1) {
        return 1;
    }
    return paths(i + 1, j) + paths(i, j + 1);
}

int main() {
    cin >> n >> m;
    grid.resize(n);
    for (int i = 0; i < n; i++) {
        cin >> grid[i];
    }
    cout << paths(0, 0) << endl;
    return 0;
}
```

```brute
#include <vector>

int main() {
    int n, m;

    vector<string> g(n);
    for (auto &s : g) cin >> s;

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {

                ways[i][j] = 0;
                continue;

            if (i > 0) ways[i][j] += ways[i - 1][j];
            if (j > 0) ways[i][j] += ways[i][j - 1];
        }
    }
    cout << ways[n - 1][m - 1] << endl;
    return 0;
}
```

### მინიშნებები

1. ყოველ მწკრივში ზუსტად ერთი ქალი დგას. ამოცანა დაიყვანება შეკითხვაზე: რომელ სვეტში დავდგათ ყოველი მწკრივის ქალი?
2. ქალი სვეტში `c` მწკრივში `r` იკავებს სვეტს `c`, ერთ დიაგონალს (`r + c` მუდმივია) და მეორე დიაგონალს (`r − c` მუდმივია).
3. შეინახეთ სამი მასივი: დაკავებული სვეტები, დაკავებული `r + c` დიაგონალები და დაკავებული `r − c + n` დიაგონალები. `go(r)`: თუ `r == n`, დათვალეთ; სხვა შემთხვევაში ყოველი თავისუფალი `c`-სთვის მონიშნეთ, გამოიძახეთ `go(r + 1)`, მოხსენით.

### ამოხსნა

```cpp
#include <iostream>
#include <vector>
using namespace std;

int n;
long long solutions = 0;
vector<bool> column, diagonalA, diagonalB;

void go(int r) {
    if (r == n) {
        solutions++;
        return;
    }
    for (int c = 0; c < n; c++) {
        if (column[c] || diagonalA[r + c] || diagonalB[r - c + n]) {
            continue;
        }
        column[c] = diagonalA[r + c] = diagonalB[r - c + n] = true;
        go(r + 1);
        column[c] = diagonalA[r + c] = diagonalB[r - c + n] = false;
    }
}

int main() {
    cin >> n;
    column.assign(n, false);
    diagonalA.assign(2 * n, false);
    diagonalB.assign(2 * n + 1, false);
    go(0);
    cout << solutions << endl;
    return 0;
}
```

ყოველი მწკრივისთვის ვცდით ყველა სვეტს, მაგრამ დაკავებულ სვეტსა და დიაგონალებს მაშინვე ვტოვებთ, ამიტომ ბევრი უიმედო ტოტი ადრე იჭრება. მათი ამოხსნა გადანაცვლებების სრული გადარჩევით `n!` ვარიანტს გადაივლიდა: `n = 10`-ზე 3,6 მილიონი, ხოლო ჭრით გაცილებით ნაკლები. ეს არის გადარჩევა ჭრით (backtracking): ნაწილობრივი ამოხსნა უკვე არასწორია → გავჩერდებით და უკან ვბრუნდებით. შეადარეთ შედეგები ცნობილ მნიშვნელობებს: 4 → 2, 8 → 92.
