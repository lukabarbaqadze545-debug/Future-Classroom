# პირველი გაკვეთილი: დაყენებიდან საკლასო ოთახამდე

ერთი გვერდი მასწავლებლისა და სკოლის ტექნიკოსისთვის. მიზანი: ერთი კომპიუტერიდან
18–20 მოსწავლის კომპიუტერთან მუშაობა სკოლის ქსელში.

> **ყურადღება.** კლასის გაკვეთილი, შესვლის კოდი და საკლასო ოთახის მართვა მუშაობს
> მხოლოდ **სკოლის კომპიუტერზე გაშვებულ ერთ ასლზე**. ვერსელზე (Vercel) ვერ
> იმუშავებს: იქ საიტი რამდენიმე ცალკე ასლად ეშვება და თითოეულს საკუთარი, ცალკე
> მონაცემთა ბაზა აქვს (გვერდი ერთ ასლზე იხსნება, „დაწყება“ — მეორეზე და
> პასუხია „ვერ ვიპოვეთ“). ვერსელი დემოსთვის გამოდგება.

## ა. ტექნიკოსი: დაყენება (ერთხელ, ~30 წუთი)

1. კომპიუტერი, რომელიც სასწავლო საათებში ჩართულია, Node.js 22 ან უფრო ახალი,
   2 GB თავისუფალი ადგილი, ქსელი, რომელსაც კლასის კომპიუტერები წვდებიან.
2. პროექტის საქაღალდეში (ტერმინალში):

   ```bash
   npm ci
   npm run build
   npm run user:create -- --role teacher --username n.beridze --name "ნინო ბერიძე"
   ```

   ბოლო ბრძანება დროებით პაროლს **ერთხელ** ამობეჭდავს. ჩაწერეთ ბარათზე; მასწავლებელი
   პირველ შესვლაზე თავისას შეარჩევს.
3. შექმენით ფაილი `.env.local` (დააკოპირეთ `.env.example`) და ჩაწერეთ:

   ```
   OPEN_ACCESS=false
   DEMO_MODE=false
   SEED_DEMO=false
   DEFAULT_LANGUAGE=ka
   PUBLIC_BASE_URL=http://192.168.1.10:3000
   ```

   (`PUBLIC_BASE_URL` — მისამართი, რომელსაც მოსწავლეები აკრეფენ; კომპიუტერის მისამართს
   ნახავთ `ipconfig`-ით (Windows) ან `ip addr`-ით (Linux).)
   **`OPEN_ACCESS=false` აუცილებელია:** მის გარეშე ანგარიშით შესვლა გამორთულია და
   საკლასო ოთახის მართვა არ მუშაობს.
4. `npm run doctor` — უნდა დასრულდეს ტექსტით „No blocking problems found“.
5. გაშვება: `npm start -- -p 3000`. გაუშვით **მხოლოდ ერთი ასლი.** ავტომატური
   გაშვებისთვის და დღიური ასლებისთვის იხილეთ `docs/OPERATIONS.md`.
6. მოსწავლეების კომპიუტერებზე ბრაუზერში დაბლოკეთ თამაშები და სხვა საიტები
   (`docs/CLASSROOM-CONTROL.md`, ნაწილი „Blocking games…“): ყველაზე მტკიცე გზაა
   „ყველაფერი დაბლოკე, ნება მხოლოდ სკოლის სერვერს“.

## ბ. მასწავლებელი: კლასი და მოსწავლეები (ერთხელ, 10 წუთი)

1. შედით თქვენი სახელითა და პაროლით.
2. **კლასები → ახალი კლასი** (მაგ. „11ა“) → შეინახეთ.
3. კლასის გვერდზე: **მოსწავლეების დამატება** → თითო სახელი ახალ ხაზზე →
   **კლასში დამატება** → **ბარათების ბეჭდვა**. თითოეულ ბარათზეა მისამართი, სახელი და
   დროებითი პაროლი. გაჭერით და დაურიგეთ.

## გ. გაკვეთილის დღეს

1. მოსწავლეები შედიან ბარათის მონაცემებით და თავიანთ ანგარიშზე რჩებიან გაკვეთილის
   მთელი დროის განმავლობაში.
2. თქვენ ხსნით **კლასები → თქვენი კლასი → საკლასო ოთახი ცოცხლად**. ბარათზე ჩანს,
   ვინ სადაა და მუშაობს თუ არა:
   - **მუშაობს** / **არააქტიურია** (2 წუთი არაფერს აკეთებს) / **სხვა ფანჯარაშია** /
     **კავშირგარეშეა**.
   - მოსწავლე აჭერს **დახმარება მჭირდება**-ს და მისი ბარათი წითლდება და ზემოთ ადის.
     აჭერთ **მოვდივარ**-ს (მოსწავლე ამას ხედავს), მერე **მოგვარდა**-ს.
3. **გაკვეთილის დასაწყებად:** **კლასები → კლასი → გაკვეთილის დაწყება** → აირჩიეთ
   გაკვეთილი → **გაკვეთილის დაწყება**. გამოჩნდება **შესვლის კოდი**
   (მაგ. `FC-4…`).
   - ანგარიშიანი მოსწავლეები მთავარ გვერდზე ხედავენ **„გაკვეთილზე შესვლა“**-ს; კოდი
     არ სჭირდებათ.
   - ანგარიშის გარეშე მოსწავლე გადადის `/join` გვერდზე და წერს კოდს და სახელს (ის
     საკლასო ოთახის ხედში არ ჩანს).
   - **პრეზენტაციის რეჟიმი** პროექტორზე აჩვენებს მისამართს და კოდს.
4. კლასის მართვა საკლასო ოთახის ხედში (მთელი კლასი, ან მონიშნული მოსწავლეები):
   **შეტყობინების გაგზავნა**, **გვერდის გახსნა**, **ეკრანების შეჩერება** (45 წუთში
   თავისით მთავრდება) და **ეკრანების გაგრძელება**.
5. გაკვეთილის ბოლოს: **სესიის დასრულება** → დადასტურება.
